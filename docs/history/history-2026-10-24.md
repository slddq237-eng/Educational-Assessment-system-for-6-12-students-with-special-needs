## 變更紀錄的舊寫法（2026-10-24 以前）
2026-10-24 改成每個 PR 在 `docs/changelog/changes/` 加一個小檔（見 `changelog.md`「怎麼寫」），原因：大家都在同一個檔案最後加一列，兩個 PR 同時開就衝突（#110 和 #109），而且要先發 PR 才知道編號、再推一次補上。`changelog.md` 原文搬來：

### 怎麼寫（每個 PR 都要）

- **發 PR 時**在最新的分段檔案最後加一列：日期｜PR 編號（連結）｜動到哪裡｜改了什麼（**一句話就好**，細節留在 PR 說明）｜想法或決定的變化（有才寫，也是一句話：從什麼改成什麼、為什麼）。這張表真正的價值在最後一欄。
- **想法或決定改了、但這次沒有改檔案**（例如開會決定、對話中改主意）：也加一列，PR 欄寫「—」，改了什麼寫「決定：…」。
- PR 還沒合併時，在「改了什麼」最後註明（**還沒合併**）；合併後拿掉。關閉沒合併的 PR 也留一列，註明（**關閉，沒有合併**）。
- 「改了什麼」寫合併當下的內容（PR 標題合併後改過的，以實際合併的內容為準）。

## A8 學會與已經會的定義（已刪除）
