# 程式依職責拆，不依大小拆；大檔案列進省 token 清單就好
- 日期：2026-11-06
- 狀態：有效
- 決定：程式檔只在職責明顯分成兩件以上、或要給別的工具共用時才拆；不為了檔案大、省 token 而拆，大檔案列進 `CLAUDE.md`「省 token」清單。文件照舊，超過 1 萬字就拆。
- 為什麼：維護者擔心為了省 token 把程式拆太碎，人工和 AI 都更難看懂檔案之間誰用誰。省 token 清單只要求 AI 先搜尋、只讀需要的段落，不改架構，就能省下大部分 token；有程式地圖 `architecture.md`，AI 搜尋得到位置。文件新增得快、舊內容容易過時，所以文件仍然要拆。
- 放棄的選項：程式檔太大就拆成小檔案（例如把 `check.js` 依檢查項目拆開）。
- 以前怎麼想：2026-11-06 Claude 曾建議 `check.js` 以後可以拆成幾個小檔案，同日收回。
