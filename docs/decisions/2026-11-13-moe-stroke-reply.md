# 教育部回信同意使用筆順資料：免另辦專案授權，但要守四個條件
- 日期：2026-11-13
- 狀態：有效
- 決定：依教育部回信（臺教社(四)字第 1150908930 號）使用《國字標準字體筆順學習網》的筆順資料：只要維持原筆畫形狀與標準筆順（不變形、不創造新字形），格式轉換、部件分色、拼圖互動、軌跡比對等功能不視為違反「禁止改作」；平臺維持免費、無廣告的公益特教教學目的並明確標示出處，就不用另辦專案授權。筆順圖（6,063 張）原樣放進 `shared/stroke/`。
- 為什麼：筆順網標示創用 CC 姓名標示－非商業性－禁止改作 3.0 臺灣版，原本以為切開、隱藏筆畫都算改作，要先申請（2026-11-07 送出）；教育部回信把範圍說得比預期寬。
- 放棄的選項：另辦專案授權（回信說不用）。
- 以前怎麼想：切出部件、隱藏筆畫、逐筆動畫都算改作，要等書面同意才能做（`parts-strokes.md` 舊第 3 節，原文在 `docs/history/history-roadmap.md`）。
- 影響範圍：授權／畫面
