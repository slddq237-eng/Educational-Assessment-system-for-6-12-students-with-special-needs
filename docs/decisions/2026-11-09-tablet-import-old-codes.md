# 平板紀錄裡名單沒有的代號，改成由老師選「併入現有學生」「新增為新學生」或「略過」
- 日期：2026-11-09
- 狀態：有效
- 決定：匯入平板作答紀錄（Google 試算表下載的 Excel）時，名單裡沒有的代號不再直接不收，而是逐一列出，附作答線索，由老師選併入現有學生、新增為新學生或略過（預設略過）。併入、新增過的舊代號記在學生的 `oldCodes`，之後匯入同一份試算表自動對應。
- 為什麼：網站從 GitHub Pages 搬到 Cloudflare Pages 時，有些老師先在新網站重新建立學生，系統給了新的隨機代號；學生以前在舊網站用平板做的紀錄只有舊代號（送到表單的紀錄不放名字），舊代號對應誰存在舊網站的瀏覽器裡、已經拿不到，所以照原本的規則整批都匯不進來。紀錄沒有名字，系統沒辦法自動用名字比對，只能讓老師依日期、年級、課次判斷是誰。
- 放棄的選項：用名字自動比對（平板紀錄裡沒有名字）；把舊代號直接照樣匯入成沒有名字的學生（老師不知道是誰，名單會多出一堆代號）；只做一次性的轉換工具（試算表之後每次下載都會再帶著舊紀錄，每次都要重選）。
- 以前怎麼想：2026-10-31 決定名單裡沒有的代號先提醒、不收進來，因為多半是已經刪除的學生或別台電腦的學生（見 `design/kid-roster.md` 第 3 個 PR）；這個顧慮仍在，所以預設是「略過」。
- 影響範圍：畫面、流程（學生名單多一個 `oldCodes` 欄；作答紀錄格式不變，匯入的紀錄存的是新代號）
