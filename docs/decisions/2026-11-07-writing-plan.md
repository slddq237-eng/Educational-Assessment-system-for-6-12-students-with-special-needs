# 寫字評量：首頁兩個入口、先螢幕出題、登錄選用、紙本沒有主題貼紙
- 日期：2026-11-07
- 狀態：有效
- 決定：寫字評量做成首頁另一個入口，背後和識字共用學生、課本、紀錄（寫字能用後再和 D9 一起做）；版本路線是第 1 版螢幕出題（學生寫在紙上）→ 第 2 版輸出考卷 → 第 3 版平板線上書寫、程式自動評分；登錄紙本成績是選用的，老師自己決定；紙本設定 3 步、沒有主題和貼紙，線上書寫保留主題和貼紙（之後規劃）。之後分析頁也拉出來做成首頁卡片「國語分析頁」。
- 為什麼：寫字用不到識字的作答方式和玩法，放在同一個設定流程會讓老師看到不相干的選項；完全分開又要複製學生名單和紀錄，同一位學生的識字和寫字也比不了。聽音寫字一定要有聲音，螢幕出題最快能用。大部分老師沒有時間逐題登錄紙本成績，所以登錄不能是必做。
- 放棄的選項：寫字完全獨立成另一個系統；先做印考卷；登錄必做；寫字沿用識字的 4 步設定。
