# 包圍字的字形尺裡面那一塊維持方框，不改多邊形
- 日期：2026-11-17
- 狀態：有效
- 決定：包圍字（左下、左上、右上…）「裡面那一塊」的字形尺維持一個方框 `[左, 上, 寬, 高]`，不改成多邊形。
- 為什麼：維護者提過多邊形（例如包的巳只佔左下一部分），Claude 做了寬鬆版試做圖（每邊多留 4.5%、橫切 3 條帶合成階梯形）給維護者看：多數字（氣、氧、勾、甸）和方框差不多；寬鬆版會蓋到外層的墨（近、魅、廳、毯蓋進 13～57%）；維護者看過後決定還是不用多邊形。
- 放棄的選項：多邊形（階梯形）。要做的話要改 `ruler.js` 資料格式（存頂點）和 `ruler-cell.js` 的畫法，考卷和練習簿都要改。

- 影響範圍：畫面（沒有改任何程式或資料）
