# 做直式生字練習簿：獨立新工具、只做直式、筆順示範用教育部圖原樣放
- 日期：2026-11-12
- 狀態：有效
- 決定：做獨立的直式生字練習簿（`tools/practice/`，和寫字考卷分開），欄由右到左、注音在字右邊，每欄是看、筆順示範、描、褪除、摺線、獨立練習；筆順示範用教育部筆順圖原樣縮放、圖放在 `shared/stroke/`；注音預設印、可取消；字從課本課次選、格子大小可選小中大、獨立練習預設自動。
- 為什麼：國小作業簿、國語習作都是直行書寫，練習的格式跟平常用的一致最穩當；筆順示範原樣放教育部圖，符合創用 CC 禁止改作，也在教育部回信同意的範圍內（`2026-11-13-moe-stroke-reply.md`）；摺線讓學生遮住示範再主動書寫；字形尺格子搬進 `shared/` 讓考卷和練習簿共用。
- 放棄的選項：橫式（維護者決定不提供）；部件示範（部件筆畫相連的字約一半切不開，會切錯筆畫，維護者決定刪掉）；用筆畫資料切部件做褪除（當時以為屬改作、要等授權；2026-11-13 教育部回信同意部件分色等功能，現在可以做，還沒排工作）；圖檔連到教育部網站（學校網路和網址變動會壞）；把圖描成 SVG（那是改作）。
- 以前怎麼想：2026-11-07 的寫字學習單構想是依筆順逐步褪除提示，且做在學習單生成器裡；改成按部件褪除、獨立新工具。
- 影響範圍：畫面／授權
