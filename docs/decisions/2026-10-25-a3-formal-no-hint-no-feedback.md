# 正式評量所有模式、所有目標都完全不提示、不回饋對錯、無對錯音效、不報讀
- 日期：2026-10-25
- 狀態：有效
- 決定：正式評量：完全不提示（含部件重組，沒有例外）、不顯示對錯回饋（選了不變綠不變紅，只有淡淡標示；新題出現後 0.7 秒內不收點選）、沒有答對答錯音效、不報讀。練習提示預設：錯 1 次語詞挖空、錯 2 次部件拆解、錯 3 次沒有提示也不顯示答案，讓學生自己點。老師提示按鈕在正式評量照常顯示並記錄（A3-9）。
- 為什麼：來源沒有寫維護者改成這樣的原因。Claude 原建議的理由是「前後測要可比，提示不能因人而異」（A3-6）；維護者後來改得比建議更嚴（A3-6、7、8、10 都標「改了」），原因來源沒有寫。
- 放棄的選項：維持原建議：正式評量保留「語詞挖空 → 圖片」兩個提示、維持畫面與音效回饋、報讀預設關可打開。
- 以前怎麼想：原本正式評量有回饋（選對變綠、選錯變紅搖動）、有對錯音效、有兩個提示、報讀預設關。
- 範圍備註：維護者 2026-11-02 確認「聽音選字」（R3）目前確實如此；其他評量目標還沒開放或在開發新功能，開放時再確認。
- 影響範圍：正式評量條件／作答紀錄／畫面
