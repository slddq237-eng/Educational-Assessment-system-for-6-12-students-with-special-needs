# 生字練習簿：切不開、不拆的字，褪除格和描一樣淡
- 日期：2026-11-23
- 狀態：有效
- 決定：維護者 2026-11-23 說「不拆的字，就維持描寫就好，不要顏色一下深、一下淺」。部件切不開或不拆的字（沒有依筆畫的部件分組），褪除兩格都和描一樣淡（濃度 22%），不再一格 50%、一格 20%。
- 為什麼：描 2 格是 22%，褪除接著一格變深（50%）再變淺（20%），學生看起來像字忽深忽淺，反而干擾；不拆的字本來就沒有部件可以蓋，維持描寫比較一致。
- 以前怎麼想：2026-11-12 練習簿第一版，切不開的字「字變淡」（兩格 50%、20%），用濃度代替逐部件褪除（`design/practice-design.md` 第 4 節）。
- 影響範圍：畫面（`tools/practice/index.html` 的 `fadeCells`，描和褪除共用 `TRACE`）。能照部件褪除的字不變。
