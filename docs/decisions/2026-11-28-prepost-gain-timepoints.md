# 前後測進步卡：同字取平均、後測分時間點，教學後天數統一分四段
- 日期：2026-11-28
- 狀態：有效
- 決定：個人頁「前後測進步」卡，同一課同一個字有多次前測或後測時各取平均；前測只算教學開始日以前。後測依「教學結束後天數」分四個時間點：一週內（含當下）0～6 天、隔一週 7～13、隔兩週 14～24、隔一個月 25 天以上；卡片主數字只用第一個時間點（進步幾個字），其他時間點另外看維持。教學結束日沒輸入時，照日期順序叫「第 N 次後測」，不猜隔多久。老師專區的「教學後天數」分組和教學結束後的直立線也改用同一組界線（原本 14～29、30 天以上）。
- 為什麼：（1）小組教學字數少，檢定很難顯著，老師更需要「進步幾個字」這種直接的數字，檢定只當輔助（至少 20 個字才顯示）；（2）教學完當下的後測問的是「學會了嗎」，隔一週、隔一個月問的是「還記得嗎」，平均會把遺忘混進學習成效；（3）老師說的「隔一個月」常是第 28 天左右，界線放 25 天比 30 天貼近實際；（4）沒有教學結束日就無法知道隔多久，貼「隔一週」標籤會誤導。
- 放棄的選項：只取最近一次（丟掉其他作答、容易受運氣影響）；後測全部混在一起平均；沿用 14～29、30 天以上（和老師說的一個月對不上）；沒日期時硬猜隔多久。
- 以前怎麼想：2026-11-27 第 1 版同字取最近一次、後測不分時間點，檢定用 McNemar。
