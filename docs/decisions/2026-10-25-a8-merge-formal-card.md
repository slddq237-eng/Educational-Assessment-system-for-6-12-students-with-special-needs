# 「學扶前後測」和「小考檢測」合併成一張「正式評量」卡片
- 日期：2026-10-25
- 狀態：有效
- 決定：合併後卡片名稱「正式評量」，多一個選項「這次是前測／後測／不標」。前後測只能在正式評量標，練習不能標；正式評量可以標前測或後測，也可以不標（維護者 2026-11-02 補充）。
- 為什麼：來源寫：兩張原本條件就一樣。
- 以前怎麼想：兩張卡片分開（學扶前後測、小考檢測）。「學扶」是學習扶助，平台之後應該不再出現這個名詞。
- 影響範圍：畫面／作答紀錄
- 來源：`docs/design/a8-terms.md` 第 11、26 點；維護者 2026-11-02 在 PR #226 留言確認
