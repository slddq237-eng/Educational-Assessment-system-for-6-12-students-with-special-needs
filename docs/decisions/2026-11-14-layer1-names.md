# 部件表第一層可以用「[名稱]」補打不出來、讀不出聲音的部件
- 日期：2026-11-14
- 狀態：有效
- 決定：第一層（人工手動）的部件，打不出來或讀不出聲音時可以用方括號寫名稱（例如「亻 [丨矢]」「[亻丨] [攵木]」），括號裡的幾個字算一塊，名稱不用讀得出聲音；遊戲和備課分析直接顯示名稱。先處理字形尺「最可能對」（LEAF+）的字：Claude 替 49 個字提議（名稱是最細部件接在一起，狀態「待確認」，備註寫來源），請老師確認或改名。
- 為什麼：要補第一層的字（字形尺不確定的 240 個，大多沒有第一層）卡在「每塊要是可讀出聲音的字」：106 個有一塊打不出來、51 個讀不出聲音；這不是 Claude 能替老師決定的，維護者決定放寬。第一層補起來，字形尺分線（`make_ruler.py`）和遮擋題（聽音補部件、看部件寫字）就都有了。
- 維護者審過的結果（2026-11-14，對照圖第 1～3 張）：兩、里、午不拆（改獨體字）；嫩拆三塊；候、索、帝、旁、憂、寡照維護者指定的畫數或線拆（見 `docs/materials/ruler-review.md`）；其他 80 個字的分線候選確認可以。第二批（對照圖第 4 張）：晉毫牽益聖舉豪賓釜黃照「前 N 畫｜其餘」拆（黃改上下），立不予介不拆（獨體字）。第三批（第 5、6 張）：南卷咧喪墩奉奧對慰懂拳揶望業照「前 N 畫｜其餘」拆，倉傘冬失方毛不拆（獨體字）。
- 放棄的選項：自動補真正的字名（兩種自動方法一致的只有 1 個字，名稱常常不是老師要的）；只在字形尺用最細部件分組、不補部件表（做不到「遮擋題」，之後仍要老師補）。
- 以前怎麼想：`parts-layers.md` 規定第一層每塊要「可讀出聲音」，打不出來的字就空著、請老師補。
- 影響範圍：教材／畫面（遮擋題會多出這 49 個字的題目；**正式評量用到的遮擋題也會多，要先告知夥伴**）
