# 包圍字「裡面那一塊」維持方框，只有「包」一個字例外用多邊形
- 日期：2026-11-18
- 狀態：有效
- 決定：維護者 2026-11-18 說「包的巳可以用多邊形包住，盡量不要包到上面的部件」。**只有包**的裡面那一塊用多邊形（階梯形：上面窄、下面寬，6 個頂點），其他包圍字仍是方框（2026-11-17 的決定不變）。
- 為什麼：包的巳有一條尾巴伸到右邊，方框要包住尾巴就會把勹的末端也包進去（放錯 14%）；多邊形可以上面窄、下面寬，不包到勹。
- 放棄的選項：全部包圍字都改多邊形（2026-11-17 看過寬鬆版試做圖，維護者決定不用）。
- 以前怎麼想：`2026-11-17-surround-rect-not-polygon.md`（全部維持方框）；這則只是加一個例外。
- 影響範圍：畫面（`ruler.js` 的資料格式多一種多邊形 `[[x,y],…]`，`ruler-cell.js` 會畫；考卷和練習簿都讀同一份）
- 來源：`docs/scripts/make_ruler.py` 的 `SURR_POLY`、`surround_poly`
