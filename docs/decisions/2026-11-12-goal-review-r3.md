# 聽音選字分析第 1 輪：總正確率含練習、反應時間看答對答錯、先不加門檻
- 日期：2026-11-12
- 狀態：有效
- 決定：①個人頁正確率顯示「全部（含練習）、前測、後測」三個數字；②新增「答對、答錯反應時間比較」，基準用該生答對題的中位數，第一版只做聽音選字和部件重組（不含聽音選部件、流暢性模式）；③前後測用 McNemar 檢定（所有課的（課，字）配對合起來），之後接「一鍵出分析報告」，現在只提示字數；④常錯的字、反應最慢的字不設門檻，加「考過 N 次、錯 M 次」；⑤容易搞混的字的 +15 個百分點、30 題、35 個字先固定，有真實資料後回頭檢查；⑥流暢性保留、不下結論，只和自己比；⑦干擾字多重標記、干擾項安排（每類各一個、老師自己挑）、聽音選部件每次送出的紀錄之後規劃。
- 為什麼：練習的提示要等第一次答錯後才出現，正確率只看第一次選取，所以不受提示影響。時間只能產生假設、不能辨認原因，所以不貼「衝動」「有困難」標籤，用自己答對題的速度當基準。前後測檢定顯著不代表教學有效，要同時顯示進步幅度。流暢性沒有常模，不能說「很慢」。
- 放棄的選項：練習另外算、只算正式評量（維護者認為練習提示在第一次選取之後，污染不多）；用所有題的中位數當快慢基準（快慢各一半是定義出來的）；四象限直接標「衝動」等標籤；常錯的字設最少考過次數。
