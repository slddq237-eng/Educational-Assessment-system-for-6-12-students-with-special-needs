# 正式評量用固定干擾字表，4 個選項，分四類（尚未實作）
- 日期：2026-10-25
- 狀態：有效
- 決定：正式評量 4 個選項（同詞、同音、形近各 1，缺的補形近）；干擾字固定（字層級、定版加版本號、只打亂位置），練習維持隨機；不用補位字；干擾字分同詞、音近、形近、形音皆近四類；部件重組形近字優先。**在固定干擾字表做出來之前，干擾項維持隨機。**
- 為什麼：採用 Claude 的建議（A3-1～5 全部「照建議」），建議理由：干擾字是「字」的特性不是出版社的特性，重複測量每次難度要相當；混合三類鑑別度最好；補位字多半沒人會選，等於偷偷減少選項。理由中標「文獻」的出自 `docs/materials/distractors.md`、`docs/design/research-method-spec.md`，標「推理」的是 Claude 的判斷、沒有查證文獻。
- 以前怎麼想：原本每次隨機抽同音、形近字，不夠用課文字補。
- 優先順序：維護者 2026-11-02 表示干擾字表的重要性目前最高，之後要做。
- 影響範圍：正式評量條件／教材／作答紀錄
- 來源：`docs/plans/a3-conditions.md` A3-1～A3-5；A8 第 18 點（紀錄加干擾字表版本、干擾字設定、錯誤類型加形音皆近）；維護者 2026-11-02 在 PR #226 留言確認
