# 前後測與研究時期是兩套標記，各管各的，資料單向相容
- 日期：2026-10-25
- 狀態：有效
- 決定：一般老師用紀錄的「前後測」欄（老師作答前按按鈕，前測／後測／空白）；研究者用研究計畫代號、版本、研究時期（事先在研究計畫設好，開始收資料後鎖定，要改只能開新版本）。研究資料可併進一般統計，一般資料不能事後標成基線期。
- 為什麼：A8 背景寫「資料三層、單向相容：練習 → 一般評量 → 研究評量。研究資料可併進一般統計，一般資料不能被當成研究時期。」
- 以前怎麼想：原本只有一套自動判斷的時期（見 `2026-10-25-a8-two-term-sets`）。
- 影響範圍：作答紀錄／正式評量條件
