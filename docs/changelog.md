# 變更紀錄（入口）

每一次 PR 改了什麼、想法或決定怎麼變，一列一筆，從舊到新排（2026-10-24 維護者要求）。用途：看出某件事每次被改動的變化流向。
現況寫在各主題文件；被拿掉的舊說法在 history 檔案；這裡只記「哪一天、哪個 PR、改了什麼、想法怎麼變」。
**平常工作不用讀這裡**（Claude 也一樣），要追某件事的變化時才讀；寫的時候只在最新的分段檔案最後加一列，不用整份讀。

## 分段檔案（依時間切開）

| 檔案 | 日期範圍 | 筆數 |
|---|---|---|
| `changelog-2026-10-20.md` | 2026-10-20～2026-10-21 | 55 列 |
| `changelog-2026-10-22.md` | 2026-10-22～2026-10-24 | 42 列 |

一個檔案快到 1 萬字（自動檢查會提醒）就開新檔，檔名用新檔第一天的日期 `changelog-年-月-日.md`，並在上表加一列；舊檔不再加。

## 怎麼看某件事的變化

- 在 GitHub 上用瀏覽器的「尋找」（Ctrl＋F），在各分段檔案搜尋關鍵字，例如「平板」「賓果」「只考有教的字」，依時間往下看。
- 「動到哪裡」欄可以先篩出相關的工具或文件；點 PR 編號可以看當時的完整說明和改了哪幾行。
- 也可以直接請 Claude 整理：「幫我整理○○從開始到現在的變化」。

## 怎麼寫（每個 PR 都要）

- **發 PR 時**在最新的分段檔案最後加一列：日期｜PR 編號（連結）｜動到哪裡｜改了什麼（**一句話就好**，細節留在 PR 說明）｜想法或決定的變化（有才寫，也是一句話：從什麼改成什麼、為什麼）。這張表真正的價值在最後一欄。
- **想法或決定改了、但這次沒有改檔案**（例如開會決定、對話中改主意）：也加一列，PR 欄寫「—」，改了什麼寫「決定：…」。
- PR 還沒合併時，在「改了什麼」最後註明（**還沒合併**）；合併後拿掉。關閉沒合併的 PR 也留一列，註明（**關閉，沒有合併**）。
- 「改了什麼」寫合併當下的內容（PR 標題合併後改過的，以實際合併的內容為準）。
