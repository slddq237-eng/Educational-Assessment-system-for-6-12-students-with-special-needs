# 多位學生：每人一條線的折線圖

- 日期：2026-10-25
- 動到哪裡：識字評量（老師專區「多位學生」）、文件
- 改了什麼：「多位學生」加四張折線圖：每天平均正確率、每天平均反應時間、每天流暢性、各課前後測正確率；每位學生一條線（8 種色盲也分得開的顏色），只畫有資料的日期，每張圖下面有「看明細表」。前後測圖用空心點＝前測、實心點＝後測，上面的課次按鈕可選看哪一課；各課前後測圖會自動判斷評量日期對不對得上（平均六成以上的學生有同一次「日期＋前測／後測」就算對上，允許有人缺）：對上時橫軸改成每次評量一格、畫前測灰／後測藍背景，選單一課且大家的教學結束日相同時再畫教學結束後的時間線；對不上就退回依日期排、不畫背景和時間線。圖上滑過去會找最近的點（含上下距離）。紀錄格式不變
- 想法或決定的變化：維護者決定折線圖不需要每天都有所有人的點，沒資料的日期直接略過；通常一起比較的學生教學和評量日期會一樣，只可能缺少，所以自動對齊
