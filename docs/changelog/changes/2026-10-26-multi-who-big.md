# 多人模式「輪到誰」放大放中間

- 日期：2026-10-26
- 動到哪裡：識字評量、文件
- 改了什麼：多位學生一起玩時，作答畫面的「輪到 ○○」改成置中放在最上方的大頭像加大名字，沒有底色和外框（`#play[data-multi]`，`play.js` 的 `startSession` 設定）；分區輪流輪到的那一區名字放大、不顯示題數、上方不重複顯示；共用賓果卡上方的「輪到 ○○」同樣放大（維護者看過第一版黃底大條覺得醜，改成不加底色、不加框）；遊戲過場的說明文字和頭像放大，海洋合作的全隊頭像放大；一個人玩不變；作答紀錄格式不改
- 想法或決定的變化：維護者要求學生要看得出輪到自己，不只遊戲，所有多人模式都要
