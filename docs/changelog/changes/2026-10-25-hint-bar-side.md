# 老師提示紀錄欄固定在畫面右邊（可改左邊）

- 日期：2026-10-25
- 動到哪裡：識字評量（`play.js`、`setup.js`、`data.js`、`index.html` 的樣式與設定面板）、`docs/design/literacy-design.md`
- 改了什麼：作答畫面的「老師提示紀錄」從題目下方一排小按鈕，改成固定在畫面右邊、上下置中的一欄，按鈕直直排；欄做得窄又扁（寬約 76px、按鈕約 36px 高），平常淡淡的（透明度 50%）、不搶眼，免得學生注意到或分心，老師手靠近或按到才變清楚；細部設定 → 畫面與聲音多一個「老師提示紀錄欄的位置」（右邊／左邊，預設右邊，存在老師電腦的設定 `hintSide`）；題目區兩側留空，不會被遮住；寬度小於 760px 的螢幕（手機）維持在題目下方
- 想法或決定的變化：老師反映下方的按鈕太小、不好按。紀錄格式不變（提示紀錄的存法沒動）
