# 部件重組的部件卡被切到：題目欄改成放不下就從頂端排
- 日期：2026-11-02
- 動到哪裡：識字評量（`tools/literacy/index.html` 的作答畫面樣式、`play.js`）
- 改了什麼：作答畫面左邊的題目欄原本「垂直置中＋可捲動」，內容比欄高時（部件重組 4 塊部件一塊一行、或提示累積很多），有些瀏覽器會讓最上面那塊超出欄外、捲也捲不到（維護者反映「蘿」第一塊部件被切掉）。改成 `safe center`：放得下照樣置中，放不下就從頂端排、往下捲看得到全部；不支援的瀏覽器一律從頂端排。部件卡大小改成最大到「題目欄一行放得下 2 張」，4 塊部件排成 2×2，通常不用捲動
- 部件提示（「艹 ＋ 罒 ＋ 糸 ＋ 隹」、黑圓圈遮中心的字）放在同一個題目欄，原本提示多到超出欄高時也會有同樣的問題，這次一起修好；手機直放的版面也檢查過
- 想法或決定的變化：沒有。作答紀錄格式沒變
- 調整（同日，維護者要求「點提示時所有提示都不會切到、也不用捲動」）：題目欄的內容（喇叭、部件、累積的提示）比欄高時，自動整體縮小到剛好放得下（`play.js` 的 `fitPrompt`、CSS 的 `zoom`；說明文字不縮），最小縮到 0.35 倍，再放不下才捲動；出新提示、換題、視窗大小改變、字型下載完都重算。手機直放、分區輪流的題目欄最高佔螢幕高 45%，超過就縮小內容，選項區不會被擠掉。提示全部出現時（語詞＋句子＋圖＋部件＋半個字＋淡字形）字會變小，分區輪流最明顯
- 調整（同日，維護者要求「提示多的時候讓左邊題目欄自動變寬」）：一個人作答的畫面，題目欄放不下時先加寬（300px 起每次加 60px，最多到作答區寬度的一半，選項區跟著變小），加寬到最大還放不下才縮小。加寬時提示可以並排（圖、部件、半個字、淡字形排成一行），聽音補部件、聽音選部件的字和喇叭並排（和分區輪流同一種排法）。提示改成排得下就並排，所以手機直放、分區輪流（只有一欄，不加寬）也比較不用縮小。換下一題時題目欄回到 300px
- 修正（同日，維護者要求截圖檢查四個開放的評量目標在電腦和平板作答的提示樣式時發現）：①聽音補部件、聽音選部件加寬的第一步還是 300px 就換成並排，太窄被左右切到，改成從 360px 起加寬，而且寬度也要放得下才算；②並排太寬時改成往右超出（`justify-content: safe center`），量得到、會再加寬，不會往左被切掉；③喇叭四周留空間（唸題目時會放大 1.06 倍、下方有立體陰影），不壓到說明文字，量寬度時也不會跟著動畫變；④「送出」按鈕不再擠成直排
