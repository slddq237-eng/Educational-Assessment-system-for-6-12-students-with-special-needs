# 更正「同一位學生重學同一課，教學日期只能存一組」的影響範圍
- 日期：2026-10-31
- 動到哪裡：文件（`docs/plans/pending.md`、`docs/design/kid-roster.md`）
- 改了什麼：更正兩處說明。原本寫「影響圖表橫軸的教學期間和『教學後天數』」；查程式後更正為：**作答紀錄不會壞**（每筆紀錄寫入時就把教學後天數存好了，`play.js` 的 `daysAfter`），**只有老師專區用現在存的日期重新算的圖會擺錯位置**（「教學開始後第幾天」橫軸、「教學結束」標記，`teacher.js` 的 `lessonPanels`、`afterEvents`），只限同一位學生同一課教過兩次的那幾張。同時補上評估結果與觸發條件
- 想法或決定的變化：評估結論是**現在不處理**（不是錯誤、資料沒壞、平台還沒有跨學年舊紀錄、還沒開放其他老師試用、修法會碰 A8 時期定義）；觸發條件＝第一次有學生要重學同一課之前，或階段 C（分析與報告）開始設計時，先到先做；暫時辦法＝改教學日期前先下載備份
- 被改掉的舊說法原文：
  - `pending.md`：「例如四年級原班學過、五年級學習扶助重學同一課，新日期會蓋掉舊日期。要決定：個別學生的教學日期改成可存多組，還是綁學期；會碰分析圖的橫軸與『教學後天數』」
  - `kid-roster.md`：「作答紀錄本身有各自的時間，不會壞；影響的是圖表橫軸的教學期間和『教學後天數』。要修就要碰分析邏輯，記在 `pending.md`，先討論。」
