# 學生分組：在學生名單編輯，教學日期、老師專區共用

- 日期：2026-10-25
- 動到哪裡：識字評量（學生名單、教學日期、老師專區「多位學生」）、文件
- 改了什麼：「學生名單」多一區「分組」：建組別、點學生加入或移出、改組名、刪組別（一位學生只能在一組，已在別組的學生按鈕會停用並標出組名；老師專區存組別時遇到重複會擋下並提醒）。教學日期的「一組學生不同」和老師專區「多位學生」的組別，改成讀同一份。設定第 2 步選學生不放組別（維護者要求）。改學生代號時，組別裡的代號一起改
- 想法或決定的變化：組別原本只能在老師專區建、只用在分析；維護者要求在學生名單就能分組並通用。存放位置不變（`literacy-teacher` 的 `groups`，只存代號），所以不改作答紀錄、不改備份格式；程式一律走 `data.js` 的 `getGroups`／`saveGroups`
- 補（同一個 PR，維護者回報）：教學日期的兩個下拉選單文字縮成「＋個別…」「＋一組…」；選一組之後只出現一列（顯示組名和人數），日期一次改整組，「改回全班」也是整組。個別設定多記一個選填欄位 `grp`（組名），只用在教學日期畫面，不進作答紀錄；組別刪掉後，那些學生就當個別學生顯示
