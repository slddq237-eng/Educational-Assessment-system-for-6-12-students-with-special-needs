# 老師專區「全班」改成「多位學生」：自己多選、可存組別

- 日期：2026-10-25
- 動到哪裡：識字評量（老師專區）、文件
- 改了什麼：「全班」分頁改名「多位學生」；預設一位都不選，自己點選最多 8 位，可把目前選的存成組別（存在老師瀏覽器的老師專區設定，只存學生代號，不進作答紀錄、格式不變）；一律算正式評量加練習、全部日期，不再有日期、性質選單（和個人畫面統一）；新增「常錯的字、反應最慢的字、容易搞混的字」每位學生一列的表格；原本的「學生 × 生字」格子保留，只顯示選到的學生，Excel 匯出也只含選到的學生。多人折線圖下一個 PR 做
- 想法或決定的變化：維護者要求同時有好幾組學生時能自己選人比較；多人版的總體紀錄、近期正式評量和練習紀錄表決定不放
