# 學生代號改成系統自動生成（學生名單管理 PR 1）
- 日期：2026-10-31
- 動到哪裡：識字評量（學生名單面板）、文件、`privacy.html`
- 改了什麼：新增學生只填名字，代號由系統產生 6 碼隨機碼（`newKidCode`）；學生名單拿掉代號編輯欄；同名時新增會先提醒；改有名字的學生的名字時提醒「紀錄和貼紙會沿用，要新增另一位請用加入」；學生名單底下新增可展開的「學生隨機碼對照表」；老師看的名稱名字不重複就只顯示名字（`kidLabel`）。既有學生的代號（例如 S01）不動，作答紀錄格式不變
- 想法或決定的變化：原本想「鎖住代號」，改成維護者提出的「代號系統自動生成」，更能避免老師改名字、沿用同一代號造成紀錄和貼紙搞混（維護者 2026-10-31）；五個 PR 的整體設計見 `docs/design/kid-roster.md`
