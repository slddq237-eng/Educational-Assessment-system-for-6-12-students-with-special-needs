- 動到哪裡：識字評量（`tools/literacy/index.html` 的樣式）
- 改了什麼：所有「字被遮住一部分」的地方，字一律放在白底、灰綠色外框的字格裡：聽音補部件的題目（被色塊遮住一塊部件的字）、遮擋字提示（只露出上半部）、部件提示裡拆不開的字（中間蓋黑圓圈）。看得出是一個完整的字格被遮住一部分，不會像畫面被切到；白底和外框顏色固定，不跟著主題變
