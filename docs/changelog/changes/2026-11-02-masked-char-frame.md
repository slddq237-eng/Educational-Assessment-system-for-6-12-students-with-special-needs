# 有遮擋的字加白底外框
- 日期：2026-11-02
- 動到哪裡：識字評量（`tools/literacy/index.html` 的樣式）
- 改了什麼：所有「字被遮住一部分」的地方，字一律放在白底、灰綠色外框的字格裡：聽音補部件的題目（被色塊遮住一塊部件的字）、遮擋字提示（只露出上半部）、部件提示裡拆不開的字（中間蓋黑圓圈）。看得出是一個完整的字格被遮住一部分，不會像畫面被切到；白底和外框顏色固定，不跟著主題變
- 遮擋字提示原本用「裁掉下半部」做（`clip-path`），外框會一起被裁掉，改成用白色蓋住下半部（和底框同色），看起來一樣是只露出上半部
- 想法或決定的變化：沒有（維護者 2026-11-02 要求「有遮擋字的評量模式或提示要有底框，最好是白底」）。作答紀錄格式沒變
- 修正（同日，截圖部件重組、聽音選部件時發現）：外框原本用陰影（`box-shadow`）畫，陰影不算在內容大小裡，題目欄放不下時量不到，最下面那個字的外框底線會被切掉（例如平板的部件重組「發」）。改成真的邊框和內距，題目欄會照常自動加寬或縮小；聽音補部件的字和遮擋色塊位置不變
