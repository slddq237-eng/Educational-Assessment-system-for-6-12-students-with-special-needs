# 識字教學單一受試研究：方法規格書

> 版本：v0.2（2026-10-20：資料分析分成日常教學與研究兩種用途）
> 來源：研究方法討論整理
> 用途：(1) 併入研究規格書；(2) 作為「教師分析後台」逐步實作的需求依據

---

## 1. 問題陳述

單一受試研究要求每個階段（尤其基線期）至少 3 個資料點，才能判斷水準、趨勢與穩定度，並排除其他因素影響。但識字教學若「每一課前測 3 次基線」，會擠壓上課與前一課後測的時間，實務上不可行。

另一個常見直覺是：「老師看第一次評量就知道學生會不會，或是亂猜矇對。」

### 1.1 觀念釐清

| 老師直覺回答的問題 | 基線期多點要回答的問題 |
|---|---|
| 這次作答是否反映真實能力（測量準確度） | 若不介入，表現會怎麼走（預測） |
| 單次判斷 | 水準、趨勢、穩定度 |
| 主觀、無法檢驗 | 資料點可供審查者檢驗 |

基線期的三項功能：

1. **預測**：建立穩定水準與趨勢，作為介入期的比較基準。
2. **排除替代解釋**：歷史事件（家長在家教、其他科目出現同字）、成熟、測驗練習效果。
3. **可檢驗性**：讓研究結論不依賴研究者的主觀判斷。

## 2. 原提案評估

### 2.1 方案一：每課前基線只測一次

- **合理性**：作為教學的形成性評量合理，符合時間限制。
- **疑慮**：
  - 每課變成「單點基線 + 介入」，本質接近前後測，不是單一受試設計。
  - 無法判斷趨勢，可能把學生原本就在進步誤判為教學效果。
  - 依 WWC 等單一受試標準，階段少於 3 點，無法認定具實驗控制。
- **結論**：適合教學紀錄，不適合當研究主要證據。

### 2.2 方案二：開學一次測完全學期基線，之後沿用

- **合理性**：方向正確，一次測多課即為多探試設計的精神。
- **疑慮**：
  - **資料過時**：後面課次的基線與介入相隔數月，期間的歷史與類化效果無法排除。
  - **缺少關鍵證據**：跨行為設計的實驗控制來自「已教的層級上升、未教的層級維持不變」。不再測未教的課，就沒有這項證據。
  - 若開學只測一次，每課仍只有單一基線點。
- **結論**：可作為初始探試，但必須在每層介入前補測。

## 3. 建議主設計：跨行為多探試設計（Multiple Probe Design Across Behaviors）

### 3.1 核心觀念

不要把每一課當成獨立實驗，而是把數課組成同一個跨行為設計。**每次探試同時測所有層級**，未教層級的基線點會在正常教學過程中自然累積。

### 3.2 步驟

1. **分層**：將課文分為 3–4 個層級（每層一課或兩課合併）。至少 3 層，才能呈現 3 次效果複製。
2. **初始探試**：連續 3 次（例如連續三天、每次數分鐘）測全部層級。
3. **介入第一層**：教學並蒐集該層介入期資料。
4. **定期全層探試**：例如每週一次，以同一張探試卷測全部層級。已教層級得到介入或維持資料，未教層級得到基線資料。
5. **介入前補測**：開始下一層前，連續測該層 1–3 次，確認基線穩定才介入。
6. 依序重複。越後面的層級，基線點越多。

### 3.3 範例時程（4 層）

| 週次 | 層 1 | 層 2 | 層 3 | 層 4 |
|---|---|---|---|---|
| 1 | 基線 ×3 | 基線 ×3 | 基線 ×3 | 基線 ×3 |
| 2–3 | **介入** | 探試 | 探試 | 探試 |
| 4 | 探試 | 補測 → **介入** | 探試 | 探試 |
| 5–6 | 維持 | 介入 | 探試 | 探試 |
| 7 | 維持 | 探試 | 補測 → **介入** | 探試 |
| 8–9 | 維持 | 維持 | 介入 | 探試 |
| 10 | 維持 | 維持 | 探試 | 補測 → **介入** |
| 11–12 | 維持 | 維持 | 維持 | 介入 |

### 3.4 降低時間成本的技巧

- **合併施測**：前一課後測與下一課基線放在同一張卷子。
- **抽樣出題**：每層隨機抽 8–10 字，閃示卡讀字，每層 1–2 分鐘。
- **探試不給回饋**：避免測驗本身成為教學。
- **納入日常評量**：探試卷當作平常小考。
- **複本輪替**：每次抽不同字或換順序，減少記憶題目效果。

## 4. 其他可選用的設計與測量方法

### 4.1 研究設計

| 設計 | 適用情境 | 優點 | 限制 |
|---|---|---|---|
| 跨行為多探試（主設計） | 單一學生、多課生字 | 時間成本低、符合標準 | 層級間需功能獨立，避免類化 |
| 跨受試多探試 | 同時有 2–3 位學生、教同一課 | 不怕字組間類化 | 需多位條件相近的學生 |
| 改良式交替處理設計（AATD） | 比較兩種識字教學法 | 速度快、基線短 | 兩組字難度須相當，有交互干擾風險 |
| 逐變標準設計（Changing Criterion） | 逐步提高識字量目標（如 5→8→12 字） | 符合循序漸進教學 | 需預先設定合理的階梯標準 |
| 簡短實驗分析（BEA） | 正式研究前，快速篩選最有效的教學策略 | 幾次教學即可比較 | 屬探索性，需後續確認 |
| 倒返設計（ABAB） | **不建議用於識字** | — | 學會的字無法「撤回」，邏輯不成立 |

### 4.2 測量方法：減少「亂猜矇對」

| 方法 | 做法 | 說明 |
|---|---|---|
| 產出型作答 | 看字念音、聽音寫字 | 猜中機率極低，優於選擇題 |
| 嚴格計分標準 | 例如 3 秒內正確念出才算對 | 區分自動化與遲疑猜測 |
| 機率校正 | 選擇題扣除隨機猜中機率 | 適用無法改產出型的情況 |
| 多題同字 | 同一字以不同形式出現 2 次以上 | 兩次皆對才算精熟 |
| 錯誤類型分析 | 記錄錯誤是形似、音似或空白 | 區分部分知識與純猜測 |

### 4.3 補充探試類型

- **維持探試**：介入結束後 1、2、4 週回測。
- **類化探試**：同一字放入新句子或新情境中測試。（2026-10-25 A8：系統先不做類化探試，功能不好做；「類化警示」這種從現有資料算的分析不受影響。）
- **社會效度**：教師、家長問卷或訪談，評估成效是否具實際意義。

### 4.4 資料分析方法：分成兩種用途

同一批探試資料，依使用者需求分成兩種分析。日常教學版只給老師看得懂、能馬上決定下一步的資訊；研究版給需要精準證據的研究人員，條件更嚴、指標更多。兩者讀同一份作答紀錄，只是呈現與計算不同。

| | 日常教學分析 | 研究分析（進階研究人員專用） |
|---|---|---|
| 對象 | 一般老師、學習扶助老師 | 撰寫論文、做單一受試研究的研究者 |
| 要回答的問題 | 學生學會了沒？下一步教什麼？ | 進步是否由教學造成（實驗控制）？效果多大？ |
| 精準度要求 | 大略趨勢即可，可容許單點判斷 | 每階段至少 3 點、條件固定、可供審查者檢驗 |
| 預設顯示 | 是 | 平常收起來，需手動開啟 |

#### 4.4.1 日常教學分析

| 方法 | 用途 | 呈現方式 |
|---|---|---|
| 正確率折線圖 | 看每層（每課）是否進步 | 一層一條線，標出教學開始 |
| 簡易目視判讀 | 只看水準（高低）與趨勢（往上／持平） | 一句白話：「這層進步中」「還沒起色」 |
| 精熟提示 | 連續 3 次達精熟標準（如 90%）→ 可進入維持 | 綠色標記 |
| 常錯字清單 | 找出要再教的字 | 依錯誤次數排序 |
| 錯誤類型簡表 | 形似、音似、空白各佔多少 | 長條圖 |
| 維持回測提醒 | 教完 1、2、4 週提醒回測 | 待辦清單 |

日常教學分析**不顯示**效果量與統計檢定，避免老師把單次結果誤讀成研究結論。

#### 4.4.2 研究分析（進階研究人員專用）

| 方法 | 用途 |
|---|---|
| 目視分析（完整六項） | 水準、趨勢、變異性、立即性、重疊、跨階段一致性 |
| 穩定度包絡線（80%–20%） | 判斷基線是否穩定，可進入介入 |
| 趨勢線（中分法 split-middle 或 OLS） | 判斷基線是否已有上升趨勢 |
| PND（非重疊資料百分比） | 簡易效果量，受極端值影響大 |
| NAP（全配對非重疊） | 較穩健的非重疊指標 |
| Tau-U | 可校正基線趨勢的非重疊效果量 |
| 隨機化檢定 | 若介入時間點經隨機決定，可做統計檢定 |
| 類化警示 | 未教層級在其他層介入後上升 → 層級獨立性不足 |
| 介入前檢核 | 基線點不足 3 或不穩定時提示「尚不宜介入」 |

研究分析的額外要求：

- 只採用**正式評量**、**探試不給回饋**的紀錄；練習紀錄一律排除。
- 每個數字旁顯示資料點數，點數不足時標示「未達單一受試標準」。
- 計算方法與參數（包絡線範圍、趨勢線算法）寫在結果旁，方便寫進論文方法章節。
- 匯出時附原始資料點，讓研究者可用其他軟體重算驗證。

## 5. 教師分析後台：功能需求（草案）

### 5.1 資料模型

```
Student      { id, name, grade, notes }
Tier         { id, student_id, name, lessons[], order, intervention_start_date? }
Item         { id, tier_id, character, alt_forms[] }
ProbeSession { id, student_id, date, type: initial|routine|pre_intervention|maintenance|generalization }
Response     { id, session_id, item_id, correct: bool, latency_sec?, error_type?: visual|phonetic|blank|other }
Phase        { tier_id, phase: baseline|intervention|maintenance|generalization, start_date, end_date? }
```

計分以「層級 × 探試」為單位：該次該層正確字數 ÷ 抽測字數。

### 5.2 功能清單（建議實作順序）

| 優先 | 功能 | 說明 | 分析用途 |
|---|---|---|---|
| P0 | 層級與字庫管理 | 建立學生、層級、每層生字 | 共用 |
| P0 | 探試紀錄輸入 | 每次探試逐字記錄對錯，可選填反應時間與錯誤類型 | 共用 |
| P0 | 多探試曲線圖 | 每層一列、共用時間軸、標示階段分隔線 | 共用（研究版加包絡線、趨勢線） |
| P1 | 自動產生探試卷 | 每層隨機抽字、順序打亂，合併為一張卷子 | 共用 |
| P1 | 介入前檢核 | 某層基線點少於 3，或未通過穩定度檢核時，提示「尚不宜介入」 | 研究 |
| P1 | 基線穩定度與趨勢 | 80%–20% 包絡線、中分法趨勢線 | 研究 |
| P2 | 效果量計算 | PND、NAP、Tau-U，逐層與整體 | 研究 |
| P2 | 維持與類化排程提醒 | 介入結束後 1、2、4 週提醒回測 | 日常教學 |
| P2 | 錯誤類型統計 | 區分部分知識與猜測 | 日常教學（簡表）／研究（逐字明細） |
| P3 | 匯出 | 圖表 PNG 與資料 CSV，供論文使用 | 研究 |

### 5.3 決策規則（可寫成後台提示）

日常教學分析只顯示最後一條（精熟 → 維持）；其餘規則只在研究分析出現。

（2026-10-25 A8：系統不定義「學會」標準，下面「如 90%」「連續 3 次」不再當預設；系統不預設基線期、介入期一定要幾筆，下面的「< 3 點」等門檻只當提示、不擋，用詞對齊也要改，見 `a8-terms.md`。）

- 基線點 < 3 → 不宜進入介入期。
- 基線最近 3 點有 80% 以上落在中位數 ±20% 範圍內 → 穩定。
- 基線呈上升趨勢 → 提示延長基線，或改用 Tau-U 校正。
- 未教層級在其他層介入後明顯上升 → 警示可能類化，層級獨立性不足。
- 介入期連續 3 次達精熟標準（如 90%）→ 可進入維持期。
