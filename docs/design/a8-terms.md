# A8 名詞與時期定義

2026-10-25 從 `docs/design/records.md` 拆出（原文搬到 `docs/history/history-2026-10-25.md`，其中有 2026-10-21 起的草案、討論過程、研究模式架構檢查）。**改紀錄格式前，這份和 `docs/design/records.md` 都要先讀。**

**狀態**：**已定案**（2026-10-25 維護者與夥伴討論後決定）。規格書（claude.ai 文件）A8 那一節請擁有者標「已定案，見 GitHub `docs/design/a8-terms.md`」。
**為什麼要優先**：名詞會寫進每一筆作答紀錄，要在試用老師（B4）開始收資料前定好。**程式：紀錄第 3 版、前測／後測按鈕、「正式評量」卡片合併已在 2026-10-25 做完（見第 5 節）**；老師專區分析頁面和研究計畫還沒做。

## 1. 背景

- 原本系統把三套名詞混在一起：每課自動判斷的「時期」（基線期、教學中、教學後、維持期）混用研究名詞和教學用語，其實只是在判斷「這課教過沒」；學扶卡片又把前測、後測硬套成時期。
- 前測／後測是老師日常用語。單一受試研究依有沒有在介入分基線期、介入期（也稱處理期）、維持期。WWC 要求每期至少 3 筆、5 筆以上完全符合，**只當參考，不當預設門檻**（第 5 點）。
- 資料三層、單向相容：練習 → 一般評量 → 研究評量。研究資料可併進一般統計，一般資料不能被當成研究時期。
- 研究方法規格書 `docs/design/research-method-spec.md` 的主設計「跨行為多探試」是每一課各自分基線、介入、維持，和這裡的做法對應；兩份文件的用詞要一起對齊。

## 2. 名詞（兩組）

| 名詞 | 值 | 誰決定 |
|---|---|---|
| 前後測（一般老師用） | 前測／後測／空白 | 老師作答前按的按鈕 |
| 研究時期（研究者用） | 基線期／介入期／維持期 | 研究者在研究計畫事先設好 |

「課程進度」（教學前／中／後）、「追蹤」、「平常」、「學會」「已經會」、學習階段判斷都已刪除（見第 1、4、10、21、22 點與 `docs/history/history-2026-10-24.md`、`docs/history/history-2026-10-25.md`）。

## 3. 決定清單（2026-10-25 維護者）

編號沿用原本的順序，其他文件寫的「A8 第 N 點」指這裡。

1. **刪掉「課程進度」**：不再有教學前／教學中／教學後這組用語，名詞只剩「前後測」和「研究時期」兩組。
2. **研究時期對應一般統計**：基線期→前測、介入期→後測、維持期→後測。
3. **一般老師專區畫面直接寫「前測」「後測」**，以老師好懂為主，不用研究名詞。遊戲設定的「前後測」按鈕只留「前測」「後測」。
4. **不要「教學中」，也不要「追蹤」**。一般畫面只有前測、後測，維持期的資料算後測。
5. **專業分析（進階、研究）不預設基線期、介入期要幾筆**：有幾筆用幾筆，筆數少只提示、不擋。
6. **兩套標記，各管各的**：
   - 一般老師：紀錄的「前後測」欄（前測／後測／空白）。判斷完全來自老師作答前按的按鈕；沒按的小考、練習留空，仍進趨勢圖，但不進前後測比較。
   - 研究者：紀錄的研究計畫代號、版本、研究時期。**事先在研究計畫裡設好每位學生、每一課各期的開始日**，學生作答時系統照計畫把研究時期寫進紀錄；開始收資料後計畫鎖定，要改只能開新版本。研究計畫內的紀錄不必再按前測、後測。
   - 單向相容：研究資料併進一般統計（第 2 點）；一般資料不能變成研究時期，也不能事後標成基線期。
7. **教學日期留著，但不再用來命名時期**：只用於圖的橫軸（教學開始後第幾天）和「教學後天數」；程式不再用它自動判斷時期。**例外只有一個提醒（2026-10-25）**：選正式評量標「後測」卻選到還沒教完的課、標「前測」卻選到已教完的課，設定第 2 步課次下面會出一句黃色提醒（多課合併一句、只提醒不擋、不改紀錄；沒填日期的課不提醒，結束日還沒到算「還沒教完」）。
8. **一般畫面的前測、後測把每個點直接列出來**，不取平均、不選哪幾筆。
9. **舊紀錄不處理對應**：現在幾乎無人使用，第 3 版直接修改格式，不寫舊紀錄（第 1、2 版）的換算或相容程式。有人要保留舊資料，改版前自己先匯出備份。
10. **不保留「平常」**：「前後測」欄只有前測、後測或空白。
11. **「學扶前後測」和「小考檢測」合併成一張卡片，名稱「正式評量」**：兩張原本條件就一樣，合併後卡片多一個選項「這次是前測／後測／不標」。
12. **前測、後測怎麼配對**：配對單位是「學生 × 課次」，依作答日期排。**沒有前後測代號，也不做補考**（2026-10-25 維護者決定，取消原本的前後測代號）：缺席的學生下次再做時，自己標前測或後測就好，每筆紀錄各自獨立；同一次坐下來考的紀錄本來就有 `session`（作答場次）。**不要求前後測考同樣的課次**，後測選的課和前測不同也不提醒、不擋。老師累積選課時，每一課各多一個後測點；沒有前測的課標「沒有前測」，不拿別課的前測來湊。
13. **前測和後測的施測條件完全一樣**：不再有「前測固定不給提示」，都用「正式評量」的固定條件（正式評量完全不提示、不回饋對錯，見 `docs/design/literacy-design.md`「提示」；選項數等其他細節由 A3 決定）。
14. **紀錄的 `phase`（時期名稱）欄刪掉**；`daysAfter`（教學後天數）保留。
15. **研究計畫日期要延後時**：開新版本，舊紀錄的研究時期維持原樣，新版本從改動日之後的紀錄開始算；**不做**「手動進入下一期」按鈕。
16. **各期開始日設給「每位學生 × 每一課」**。
17. **一位學生同時只能參加一個研究計畫**：紀錄只需存一個計畫代號。
18. **第 3 版一起定的欄位**：干擾字表版本與干擾字設定、錯誤類型加「形音皆近」。**不做**形近細分「同部件」或「筆畫」。E4 的複選欄位不在這裡預先定，見第 24 點。
19. **教學日期的修改只留「修改紀錄」**（哪天改、從什麼改成什麼），不再問老師是「修正錯誤」或「計畫變更」。
20. **三種畫面誰看得到**：一般和進階放在老師專區現有的選項（分頁）中；研究畫面要有研究計畫才看得到。
21. ~~「學會」的標準~~、22. ~~「已經會」~~：全部刪除，系統不定義；原文見 `docs/history/history-2026-10-24.md`「A8 學會與已經會的定義（已刪除）」。
23. **字層級的分析只做三項**，放在一般分析畫面（做分析頁面時一起做）：常錯的字、反應最慢的字、容易和什麼字搞混。
24. **E4「聽音選部件」的複選欄位不在第 3 版預先定**：E4 開工時再加欄位。紀錄格式規則是「只加新欄位、不改舊欄位的意思」就不用升版，所以不會逼出第 4 版。**2026-10-31 步驟 4a 已加（維護者決定）**：新增 3 欄，加在 Excel 欄位最後面：「聽音選部件：正確部件」（`answerSet`，這題的答案，空格分開、重複照寫，例如「木 木 木」）、「聽音選部件：最後選的部件」（`pickSet`，最後送出的選擇）、「部件取自第幾層」（`partsLayer`，2 或 3，部件資料之後老師會改，所以記當時的）；其他沿用現有欄位：選項數、全部選項（部件）、第一次選的（第一次送出的部件）、第一次就答對（第一次送出就全對）、答錯次數（送出但沒全對的次數）、最後答對；錯誤類型加兩種值：「少選」（選的都對但沒選完）、「選到干擾部件」（含同一個部件選太多張）。紀錄格式版本仍是第 3 版，沒有升版。**聽音補部件（R5，2026-10-31 步驟 4b）再加 2 欄（維護者決定）**：「聽音補部件：被遮的是第幾塊」（`maskIdx`，照第一層的順序數）、「聽音補部件：字的結構」（`maskStruct`，當時的結構，之後老師改了也查得回來）；被遮的部件記在 `answerSet`、`partsLayer` 記 1，選的部件記在現有的「第一次選的字」；錯誤類型「選到干擾部件」；「正確部件」那一欄的表頭改成「部件題的正確部件（聽音補部件、聽音選部件）」（欄位位置不變，只是兩個目標共用）。
25. **研究計畫的各期開始日自己存一份，鎖定後不跟教學日期連動**：研究計畫開始收資料時把各期開始日複製一份鎖起來，之後老師改教學日期，不會動到已記下的研究時期。
26. **「前測／後測」只能在「正式評量」標**（快速開始的「正式評量」卡片，和進階設定選正式評量時）；練習一律不能標。
27. **類化探試不做**（功能不好做）；「類化警示」這種用現有資料算的分析不受影響。
28. **研究資料的探試類型併入一般統計時**：基線期的初始探試、介入前補測、未教層的例行探試→前測；介入期→後測；維持期→後測。
