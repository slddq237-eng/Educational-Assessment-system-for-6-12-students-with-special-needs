## 1. 做法

- **部件＝一段筆畫範圍**：例如「清」第 1～3 畫是氵、第 4～11 畫是青。網頁照範圍把那幾筆畫出來（SVG，網頁畫圖的格式），部件和整字的字形完全一樣，也能顯示部件在字裡的變形（例如「林」左邊的木最後一筆是點）。
- **部件可以不連續**：「國」的囗是第 1、2、11 畫（最後封口），寫成 `1-2,11;3-10`（部件之間用 `;`，同一部件的不連續段用 `,`）。
- **筆畫範圍可以自動算**：用部件表的拆法加上筆畫數，照書寫順序累加；包圍結構（國、這、或）試各種「外框先寫幾畫」的順序，用筆畫形狀比對選最合理的。
- 構想來源：雄筆順（顏國雄老師的網站）也是用筆畫範圍切部件。**只參考做法**，沒有用它的資料檔、程式碼、畫面（它的資料檔標明 All rights reserved）；做法本身不受著作權保護（著作權法第 10 條之 1）。

## 2. 本機試驗結果（2026-11-02）

拆法用 cjkvi-ids（之後改用部件表第一層），部件筆畫數用 Unicode Unihan，筆畫用 g0v zh-stroke-data。教育部 4808 常用字：

| 狀態 | 字數 | 說明 |
|---|---|---|
| 自動 | 4,470（93%） | 抽查 100 字沒有拆錯；包圍類 139 字中「彪」「幾」兩字可疑 |
| 建議確認、需人工 | 56 | 大多是對的，只是分數低 |
| 無法拆 | 98 | 筆畫數對不上（54）、交疊結構（29，如中、串、來）等 |
| 拆字表用了沒有編碼的部件 | 55 | 如馬、鳥、龍；改用部件表的拆法後應該會變少 |
| 獨體字、沒有筆畫資料 | 129 | g0v 沒有「乃」「粄」 |

腳本和結果只放在本機，**不放進 repo**（結果是從教育部筆畫算出來的，等授權確認）。

## 3. 授權：教育部已回信同意（2026-11，免另辦專案授權）

- 筆畫資料來自教育部《國字標準字體筆順學習網》，g0v 是從網站取得的。網站[版權說明](https://stroke-order.learningweb.moe.edu.tw/page.jsp?ID=52)寫明：「筆順動畫」「全筆順提示」採**創用 CC 姓名標示－非商業性－禁止改作 3.0 臺灣版**。
- **教育部回信**（臺教社(四)字第 1150908930 號，維護者 2026-11-12 收到；信的全文由維護者保管，不放進 repo，內有個人資料）：
  1. 只要確保維持原筆畫形狀與標準筆順（不變形、不創造新字形），所規劃的**格式轉換、部件分色、拼圖互動與軌跡比對**等功能，**不視為違反**創用 CC 的「禁止改作（ND）」規範。
  2. 平臺若屬**免費、無廣告**的公益特教教學目的，且承諾**明確標示出處**並**維護標準字形筆順**，在遵守「創用 CC 姓名標示－非商業性－禁止改作 3.0 臺灣版」授權規範的前提下，就可以依規劃的方式進行教學利用，**無須另行辦理專案授權申請**。
- **要遵守的條件**（做這一節的任何功能都要符合）：①保持**原筆畫形狀和標準筆順**，不變形、不新造字形；②**免費、無廣告**，不商用；③**明確標示出處**（`about.html`、`materials/data-sources.md`、使用筆順圖的頁面）；④筆順圖放進 repo 的資料夾要寫明授權（`shared/stroke/README.md`），不適用專案其他部分的授權。
- **信裡沒逐字寫到的**：把部件的筆畫「隱藏」（褪除、聽音補部件不畫被遮的筆畫）、用筆順動畫逐筆寫出。這些和信裡的「部件分色、拼圖互動、軌跡比對」同一類（都不改筆畫形狀），**但不是信裡的原文**；做的時候在 PR 說明標出，有疑慮再請教教育部。
- **全字庫正楷體不能代替**：字型的筆畫黏在一起（例如「國」11 畫，字型只有 7 個外框），切不出單一筆畫。
- **原本的申請經過**（2026-11-02 起）已搬到 `docs/history/history-roadmap.md`「從 parts-strokes.md 第 3 節移來」。

## 4. 可以做的事（授權已取得，要做時再排工作）

| 功能 | 改成 | 好處 |
|---|---|---|
| 部件顯示（提示、選項、備課分析） | 有筆畫資料的字畫 SVG，沒有的退回字型 | 字形統一；沒有 Unicode 的部件也畫得出來 |
| 部件重組（R4） | 拼圖塊用筆畫切出來 | 拼對可以無縫組回整個字 |
| 聽音補部件（R5）、看部件寫字（W3） | 不畫被遮的那幾筆（`fill: transparent`），不是塗成底色 | 不規則部件也遮得準；塗成底色會蓋掉交叉的筆畫和田字格線 |
| 答對之後 | 用筆順動畫把補上的部件一筆一筆寫出來 | 順便教筆順 |

- 要先定：部件單獨出現時用哪個字的字形（代表字）、顯示在原位或放大置中、筆畫資料怎麼精簡成網頁讀的檔案、資料檔要不要放進公開 repo（依教育部回覆的範圍）。
- 部件表要多一欄「筆畫範圍」，由程式自動填、老師看預覽圖確認。
