## 3-2. 老師專區（分析）設計（2026-10-20 定案）

參考賓果老師專區的呈現方式（數字卡、折線圖、常錯字、容易搞混的字、字的精熟歷程表），但依識字評量的紀錄格式重新做。**不一次攤開所有數據，用選單逐步選，每次只顯示一張圖或一張表＋上方 3 個重點數字**，明細按「看明細」才展開。

| 選單 | 選項 |
|---|---|
| 1 看誰 | 一位學生（預設）；多位學生比較（全班總表：學生 × 生字，格子顯示正確率） |
| 2 怎麼看 | 依時間（橫軸選「測驗日期」或「教學時間」＝教學開始後第幾天，對齊各課教學日期）；依課別；依時期比較（基線期／教學中／教學後／維持期並排） |
| 3 範圍 | 本學期（預設）、上學期、自訂起訖日期、某一時期；另可篩正式評量（預設）或練習、評量目標、課次 |
| 4 看什麼（一次一個） | 錯誤率（正確率）、反應時間、流暢性（每分鐘正確數）、間隔（教學後天數、距上次評量天數）、常錯字排序、高字頻生字（常用字）錯誤率、錯誤類型、提示層級 |

- **錯誤類型分析**（2026-10-23 加，`teacher.js` 的 `etype`、`chanceOf`、`wposNote`）：除了各類次數與比例，另算「亂猜會佔」（畫面用語，2026-10-23 維護者決定；倍數只用來判斷、不顯示在畫面上）——每一題選錯時，各類字在那一題干擾字裡占幾分之幾，加總成預期次數；實際比例是它的 1.5 倍以上、至少錯 3 次的類別列在上方「特別容易搞混」（小字寫實際比例和亂猜會佔多少），錯的題目少於 5 題顯示「樣本數不夠」，沒有符合的顯示「看不出錯誤類型，接近亂猜」。起因：干擾字的組法固定先放 1 個同詞易混字，3 選 1 時它就占干擾字一半，只看比例會高估「同詞易混」。選項類別用 `play.js` 的 `optType` 依**現在的**教材重新判斷（紀錄只存選項的字，沒存類別），教材改過可能和當時略有不同；不改紀錄格式。說明最後附「目標字在詞首／詞尾」的第一次就答對率與同詞易混次數（`wposOf`，進階分析也用），用來看語詞是不是整塊記、字還沒分出來（老師觀察：智能障礙學生詞層級全對、字層級常選成同詞另一字）。
- 選單只顯示合理的組合：趨勢類（正確率、反應時間、流暢性）畫折線圖；排序類（常錯字、錯誤類型、高字頻）顯示排序表。
- 依時間的折線圖：預設每課一張小圖（見下方「依時間」），背景顏色表示時期、虛線分隔各時期，並標出教學安排（原班／資源班／學習扶助）的開始日；流暢性可畫目標線。
- **逐字學習紀錄**：任何畫面點一個字，就看到那個字的每次作答（日期、時期、目標、對錯、秒數、選錯成哪個字、提示層級、當時的時期）。
- 目前畫面的資料可以匯出 Excel。
- 高字頻生字錯誤率用 `shared/freq.js`（2026-10-20 匯入），可選字頻前 100／300／1000 名；程式仍保留「沒有字頻資料時這個選項不出現」。
- **分析與比較一律用時期（基線期／教學中／教學後／維持期）判斷。**（2026-10-20 定案；**2026-10-25 A8 決定刪掉教學前／中／後，改成前測／後測，程式還沒改，見 `records.md`「A8」**）
- **學習階段（獲得／流暢／精熟／維持）保留為簡單的效果檢核**：老師專區基本頁面有一張「學習成效一覽」，每個字標出已達習得、精熟、維持或還沒達到，讓老師大略瀏覽；不放進進階分析。判斷標準待討論（見待決問題）。
- **間隔兩種都要**：教學後天數（該課教學結束到這次評量）、距上次評量天數（同一學生同一字）。

### 第 2 階段的實作細節（2026-10-20）
- 右上角「老師專區」，三個分頁：一位學生、全班總表、進階分析（研究用）。中途結束的紀錄一律不算；預設只看正式評量、本學期。
- 一位學生：看誰 → 看什麼 → 怎麼看（趨勢類才有）→ 範圍（日期、正式／練習、課本與課次、評量目標）。每次一張圖＋3 個重點數字＋「看明細」表格＋匯出 Excel。
  - 正確率＝第一次就答對的比例；反應時間＝答對題的平均秒數；流暢性＝每回合第一次就答對的題數 × 60 ÷ 時限。
  - 依時間：橫軸可選測驗日期（每次評量一個點，照評量先後每次一格、只在換日處標日期，同一天評量好幾次也分開畫；2026-10-24 維護者回報同一天的點疊成一條直線後改，原本照日期排）或教學開始後第幾天（只算有教學日期的課，各課對齊自己的教學開始日）；教學安排開始日畫直線；流暢性畫目標線。
  - **每課分開**（預設，2026-10-24 維護者決定，`teacher.js` 的 `lessonPanels`）：一課一張小圖、上下排、橫軸和縱軸都共用（單一受試研究的多基線圖，對應研究方法的跨行為多探試設計）；最上面加一張「全部課合計」（每次評量全部的課合起來一個點，不塗時期、不畫虛線，看整體起伏；2026-10-24 維護者要求）；可切回「合併成一條」。起因：時期是每一課各自算的，全部合成一條線時，同一次評量含好幾課，只能標最多題目的時期，畫面上時期來回跳。
  - **時期用背景顏色**（2026-10-24 維護者決定）：基線期淡灰、教學中淡藍、教學後淡綠、維持期淡黃、未判斷不塗色；圖上方有顏色對照（圖例），改變處仍畫虛線，圖上不再寫時期名稱；滑鼠移到點上仍顯示時期。不到 3 題的點畫空心，提醒數字容易大起大落。舊說法見 `docs/history/history-2026-10-24.md`「折線圖標時期名稱的說法」。
  - 間隔分組：教學後天數（教學前或教學中／0～6／7～13／14～29／30 天以上）、距上次評量（第一次考／同一天／1～6／7～13／14～29／30 天以上）。
- 全班總表：學生 × 生字，格子是第一次就答對比例與次數，顏色只用一種藍色（越深越好）。
- 逐字學習紀錄：任何畫面點字就打開，列出那位學生那個字的每一次作答（含標註的中途結束），可匯出。
- 進階分析：1 個指標（筆數、正確率、錯誤率、答對秒數、第一次作答秒數、流暢性、提示層級、用到提示比例、顯示答案比例、兩種間隔天數）× 列 × 欄（29 種分組，以 `tools/literacy/pivot.js` 的 `DIMS` 為準，2026-10-23 對照：見下方「進階分析」表格），2 個篩選、日期、只算每個字第一次作答、排序、筆數提醒門檻、長條圖／折線圖、存成我的比較、匯出結果＋原始紀錄。目前一次一個指標。
- 圖表顏色依資料視覺化規範：一條線用第 1 色，多組用固定順序 8 色（已用色盲檢查工具驗證，淺色組靠表格與標籤輔助）；格線是實線細線，只有時期分隔用虛線（單一受試研究的慣例）；時期的背景色是很淡的顏色，不靠顏色單獨分辨（有圖例、虛線、滑鼠提示）。
- 自動化測試用已知答案的假資料逐項比對（21 項全部通過），包含進階分析與從原始紀錄直接算的結果一致。

### 進階分析（研究用，平常收起來）

給有研究需求的老師做交叉比對。放在老師專區的「進階分析」分頁，一般老師不會看到。做法是「樞紐分析表」（像 Excel 的樞紐分析：選要比什麼、依什麼分組，系統算出每一格的數字）。

| 設定 | 可以選 |
|---|---|
| 指標（一次一個或多個） | 錯誤率、反應時間（第一次作答／答對秒數）、流暢性、間隔、常錯字排序、高字頻生字錯誤率、錯誤類型分布、提示層級 |
| 列（第 1 個分組） | 29 種（2026-10-23 照程式）：字、學生、時期、課別、課本、評量目標、評量方式、選項數、版面（呈現方法）、作答模式、提示方法（當時設定）、答錯規則、用到的提示層級、第一次的結果／錯誤類型、主題、遊戲玩法、血量模式、選項注音、報讀提示、正式或練習、教學後天數（分組）、距上次評量（分組）、日期（週）、日期（月）、常用字加題、作答字的大小、字頻（分組）、目標字在語詞的位置（詞首／詞中／詞尾，從紀錄的字和語詞推算）、裝置 |
| 欄（第 2 個分組，選填） | 同上 |
| 篩選 | 上面所有欄位都能篩，另加日期區間、只看第一次作答 |

- 每一格同時顯示**筆數**；筆數太少（預設少於 5 筆）的格子變淡並提示「資料太少，僅供參考」。
- 可切換成長條圖或折線圖；結果與篩選後的原始紀錄都能匯出 Excel，方便用 SPSS 等軟體再分析。
- 常用的設定可以存成「我的比較」，下次直接開。
- 紀錄要補記的欄位：答錯規則、提示方法（目前只記用到的提示，要另記「當時設定」）、版面（第 0 階段一併加）。

### 單一受試研究方法與分析分層（2026-10-20 維護者提出）

完整內容見 `docs/design/research-method-spec.md`（識字教學單一受試研究方法規格書：跨行為多探試設計、測量方法、教師分析後台需求）。重點：

- 每課只測一次基線＝前後測，不能當研究證據；改用**跨行為多探試設計**：課文分 3～4 層，每次探試同時測所有層，未教的層自然累積基線點，介入前再補測 1～3 次。
- **資料分析分成兩種用途**，讀同一份作答紀錄：
  - **日常教學分析**（預設顯示）：正確率折線圖、白話的水準與趨勢、精熟提示、常錯字、錯誤類型簡表、維持回測提醒。不顯示效果量與統計檢定。
  - **研究分析**（進階研究人員專用，平常收起來）：完整目視分析、80%–20% 穩定度包絡線、趨勢線、PND／NAP／Tau-U、隨機化檢定、類化警示、介入前檢核；只用正式評量、探試不給回饋的紀錄，點數不足標示「未達單一受試標準」。

### 學扶前後測與快速指南（2026-10-20 維護者提出）
給學習扶助、資源班老師做轉介前介入（RTI）的前後測，資料要能用在特教鑑定的心評報告。決定不另做專區、也不放進一般設定，而是在快速開始加一張卡片，搭配一頁快速指南。
- **快速開始「學扶前後測」卡片**（2026-10-25 A8 決定：和「小考檢測」合併成「正式評量」，選項改成「前測」「後測」「不標」，程式還沒改）：正式評量、條件全部固定。老師只要選「現在是？教學前／教學中／教學後」→ 學生 → 課次 → 開始。
  - 教學前＝基線期（固定不給提示）；教學中＝教學中；教學後＝教學後，該課教學結束已超過「維持期」天數（預設 7 天）就自動算維持期。
  - ~~按開始時自動記日期~~（2026-10-21 拿掉，錯誤修正）：原本把「今天」記成教學開始日或結束日，但老師常教完一陣子才做後測，日期會記錯，還會改到一般評量的時機判斷。現在教學日期只由老師在「教學日期管理」自己輸入；選「教學後」時，有填結束日而且已超過維持期天數才算維持期。
  - 待討論（維護者 2026-10-21 提出，併入 A8）：卡片改名「前後測」、只分前測和後測、條件和小考檢測一模一樣，紀錄加「前後測」欄。
- **計時挑戰改成練習**（2026-10-21 維護者決定）：快速開始的「計時挑戰」＝練習＋流暢性模式（1 分鐘），結果另外統計、不列入學習分析；老師專區把「性質」切到「練習」或「全部」就看得到流暢性圖。要列入學習分析，到進階設定選「正式評量＋流暢性模式」。
  - 這台電腦記住上次用的卡片（localStorage `literacy-preset`）；「現在是？」每次都要重選，避免選錯時期。
  - 紀錄的時期照老師選的；「教學後天數」照教學結束日算（結束當天＝第 0 天）。
- **快速指南** `tools/literacy/guide.html`：第一次使用、每次評量 4 步驟、什麼時候做（前測至少 3 次）、寫報告要看老師專區哪裡、一定要記得（中途結束不算、每週備份、匯出檔有學生名字）。可列印成一張 A4。識字評量右上角「選單 → 使用說明」、平台首頁都有連結。
- **之後再做：老師專區「報告摘要」**（等累積真實資料）：選學生和課別，一鍵整理前測／後測的正確率、反應時間、流暢性、進步與仍需加強的字、常見錯誤類型、介入節數與開始日，附可以直接複製進心評報告的文字和 Excel。細節待決（見本檔「報告摘要要先決定的事」）。
- **換人提醒方式（2026-10-20 維護者要求）**：預設「畫面＋提示音」（三個往上跳的小音），不唸名字；「⚙ 細部設定 → 畫面與聲音」可改成畫面＋唸出名字、畫面＋提示音＋唸名字、只有畫面。畫面一定顯示大頭像和「換 ○○」。
- **右上角計時（2026-10-20 維護者要求）**：作答畫面右上角顯示「⏱ 分:秒」（這一次已經玩了多久）。練習預設顯示，可在「⚙ 細部設定 → 畫面與聲音」關掉；正式評量預設**不顯示**（看得到時間可能讓學生緊張、影響反應時間），要顯示到「⚙ 細部設定 → 評量設定」打開，而且從基線期起就要一直維持同一個設定。流暢性模式一律顯示「⏱ 剩 ○○ 秒」。每筆紀錄記下 `clock`（有沒有顯示計時），Excel 欄位「顯示計時」。只是顯示，不影響反應秒數的計算。

## 3-4. 備課分析（2026-10-20 新增）

給老師備課用：選課本（可多本，例如同年級）、勾課次或存好的段考範圍，統計範圍內常見部件，作為集中識字（部件識字、基本字帶字）的教學重點參考。

- 範圍：課本可複選；課次可勾選；字的種類（習寫＋認讀／只習寫／只認讀）。常用範圍存在瀏覽器 localStorage（`prep-ranges`），畫面狀態存在 `prep-ui`。
- 分析方式：第一層部件（字直接拆開）或拆到最細（部件再往下拆）；預設隱藏單一筆畫；可設定「至少出現在幾個字」。
- 結果：三個重點數字＋三個分頁。部件排行列出出現字數、出現率、範圍內的字、**學過的舊字**（同版本、比範圍更早的課，用來新舊字串聯）；生字一覽列出每字部件與語詞；字頻分頁在 `FREQ`（字 → 排名）存在時才有內容。目前分頁可匯出 Excel。
- 部件來源（備課分析、識字評量的部件提示都一樣）：先用 `lessons.js` 的 `PARTS`（人工），沒有再用 `shared/parts.js` 的 `PARTS_AUTO`（cjkvi-ids 自動拆解，GPLv2，優先台灣字形；罕用部件再往下拆成常見部件；相容表意字轉回一般字；無法編碼的部分略去）。
- 已知限制：自動拆解是「字形結構」，不一定等於教學用部件，例如「王」拆成一＋土、「只」拆成口＋八。發現錯誤可直接改 `shared/parts.js`，或在 `lessons.js` 的 `PARTS` 加人工拆法（優先採用）。重新產生 `parts.js` 會覆蓋手改內容，所以人工修正建議寫在 `PARTS`。
- 字頻：`shared/freq.js`（2026-10-20 匯入，字頻分頁已有內容）。待做：詞頻資料、部首與筆畫（Unicode Unihan 或全字庫，目前開發環境連不到）、課文詞頻（需要課文）、課本的下學期與「學年度」。
