# 聽音補部件：一題的選項怎麼產生（2026-11-21 現況；聽音選部件用筆畫畫選項見第 9 節）

聽音補部件（R5，只有練習）每題 4 個選項：1 個答案（被遮住的那一塊部件）＋ 3 個干擾部件。這份把程式的做法從頭到尾寫成步驟，方便老師知道選項從哪裡來、想調整時改哪裡。
決定的經過見 `parts-layers.md`「部件選項池」；部件三層、遮哪一塊、色塊位置見 `parts-layers-impl.md` 第 6 節；用教育部筆畫畫字見 `parts-strokes.md` 第 4 節。
程式都在 `tools/literacy/play.js`（`makeFillOptions`、`fillLead`、`partDistractors`、`partSources`），出題範圍在 `tools/literacy/data.js`（`fillIdxs`）。

## 1. 先決定遮哪一塊、用筆畫還是色塊

1. 這個字照部件表**第一層**拆成 2～3 塊（例：清＝氵｜青）。
2. **有教育部筆畫、而且筆畫分組和第一層一塊對一塊的字**（`strokeMaskOf`）：用筆畫畫字，每一塊都可能被遮（包圍的字只遮裡面），選項也全部用筆畫畫。
3. **沒有筆畫的字**（或這次筆畫下載失敗）：用色塊遮，選項用文字。這時只遮「是一個字、楷書字型有收」的那幾塊（`fillIdxs`）：「上半」「龸口」這種部件表的名稱、龶這種字型沒收的部件，用文字顯示不出來，就不遮它；一塊都不能遮的字不出題（筆畫正常時約 18 個字，例如旁、聽、原、度）。
4. 練習每題從能遮的幾塊裡**隨機**挑一塊。

## 2. 找干擾部件：先依遮的位置找（甲、乙）

**甲、同部件形近**（`fillLead`）：留下的部件不變、只換被遮的那一塊。
1. 在全部課本字裡找：第一層塊數一樣、結構一樣（都是左右、都是上下…），而且**除了被遮的位置以外，每一塊都和這個字一樣**的字。
2. 取那個字在被遮位置的那一塊。例：清遮「氵」→ 晴（日｜青）、睛、精、猜 → 日、目、米、犭。學生選了會拼成另一個真的字，看得出是不是同家族的字搞混。
3. 排順序：這個字的**形近字**（課本資料的形近字清單）優先 → **同一課**的字 → 其他課本字；同一級裡隨機。
4. 留下的部件如果是「上半」「下半」這種名稱，就不找甲（同一個名稱在不同字裡是不同形狀，比對沒有意義）。

**乙、形近部件**（`fillLead`）：長得像被遮那塊的部件。用現有資料找兩種：
1. 被遮的部件自己的第一層，和另一個部件在**同一個位置有相同的部件**、結構也一樣。例：青（龶｜月）和責（龶｜貝）→ 遮青時出責。
2. 被遮的部件本身是一個字、它的**形近字清單**裡有的部件。例：馬 → 鳥；口 → 日、田。
3. 不放包含被遮部件的、或被遮部件包含它的（例：遮少不出沙）。
4. 這兩種資料只有約 21% 的遮法找得到；被遮的多半是氵、木、口這種簡單部件，要完整得建「形近部件表」（`pending.md`，等試玩回饋再決定）。

**搭配**：3 個位置裡甲**最多先放 2 個、留 1 個給乙**；乙找不到就再放甲，甲也不夠就往下一步補。

## 3. 不夠的用原本的方法補

依序從這些字拆出來的部件（第二層）裡隨機挑，湊滿 3 個為止：
1. 這個字的形近字
2. 同一課的其他字
3. 全部課本字

## 4. 每個候選都要過的排除規則（`partDistractors`）

甲、乙、補的部件都一樣，不符合就跳過換下一個：
- 不是答案本身、不是畫面上看得到的其他部件（清遮青時不放氵）
- 不是這個字三層裡的任何部件、也不是這個字本身（表的龶就是上半，放了等於兩個對的）
- 不是完全由答案的部件組成的（答案木時不放林）
- 不是單一筆畫（一、丨、丿、丶等）
- 是一個字（不是「上半」這種名稱）、不是罕用字（Unicode 編號 U+20000 以上）
- 用筆畫畫時：要切得出筆畫（某個課本字的第一層有這個部件、而且有筆畫）；用文字時：楷書字型要有收
- 不重複

## 5. 用筆畫畫時，每個選項從哪個字切

- **答案**：這個字被遮的那幾筆，形狀和洞完全吻合。
- **甲找到的部件**：直接從找到的那個字切（例：日從晴切），位置一定相同。
- **其他部件**（`partSources`）：在「第一層有這個部件、有筆畫」的課本字裡挑，**結構和位置都一樣**的優先 → 位置一樣 → 任何一個，同一級裡隨機。
- 畫法：那幾筆等比例放大置中（只縮放、不變形；共用的 `shared/strokes-api.js` 的 `Strokes.svg`），出處標在題目下面。

## 6. 作答紀錄

照舊只記部件名稱（例如「上半」「日」），錯誤類型都記「選到干擾部件」，不記是甲、乙還是補的，也不記從哪個字切。要在老師專區分開看「選到同家族的字」「選到形近部件」得新增錯誤類型，屬改紀錄格式，要先全體討論（A8）。

## 7. 想調整時怎麼做

| 想改的 | 改哪裡 |
|---|---|
| 某個字的干擾部件不好（太簡單、太像、不適合） | 截圖給 Claude；通常是改那個字的形近字（課本資料 `shared/lessons-*.js` 的 `CONF_ED`），或改部件表的拆法（`docs/materials/parts-table.xlsx`） |
| 某個部件用筆畫畫出來形狀怪（例如從吾切的口太扁） | 截圖給 Claude；之後加一份「部件代表字表」指定這個部件固定從哪個字切（`parts-strokes.md` 第 4 節，之後做） |
| 想要更多「長得像」的干擾部件（乙） | 建「形近部件表」（`pending.md`，之後再決定）：可用教育部筆畫比形狀算候選、老師勾選 |
| 甲乙的比例、補的順序、排除規則 | 改 `play.js` 的 `fillLead`、`partDistractors`，同步改這份文件 |

## 8. 檢查結果（2026-11-21）

全部 5,557 題（有筆畫）：選項都是 4 個、不含這個字自己的部件和本字、每個選項都切得出筆畫；干擾部件 9,013 個是甲、1,348 個是乙，1,520 題（27%）甲乙都找不到、全用第 3 步補。筆畫下載失敗的情況 5,125 題：選項都是 4 個、都是字型有的字。

## 9. 聽音選部件（R6）也用筆畫畫選項（2026-11-21）

聽音選部件的答案是第二層部件（例：清＝氵、龶、月），和教育部筆畫的分組（第一層）不一定一樣，所以做法和聽音補部件不同：
1. **整題一致**：這個字的答案部件**全部**切得出筆畫（第 5 節的 `partSources`：某個課本字的第一層有這個部件、而且有筆畫），這題 6～7 張選項就全部用筆畫畫，干擾部件也要切得出筆畫；有一個答案部件切不出來，整題用文字（一題裡不混用）。
2. **從哪個字切**：答案部件剛好是這個字第一層的一塊時，直接從這個字切（例：冷的冫、令都從冷切，形狀最準）；其他從別的課本字第一層同名的那一塊隨機切（例：清的龶從責切、月從朋切）。所以部件可能是它在別的字裡的寫法（例：森的木可能從「村」切，是左邊窄的木）。
3. **出題範圍**：答案部件要都能顯示：都是楷書字型有收的字，或都切得出筆畫（`data.js` 的 `pickShowable`）。原本字型沒有、會借用裝置字型跑位的部件（龶、冫、丷…），有筆畫就改用筆畫畫；兩種都不行的字不出題（筆畫正常時新增 64 個不出，例如通、立、門、師；筆畫下載失敗時更多），設定畫面會寫出原因。
4. **干擾部件也先照甲乙找**（2026-11-21 維護者決定，`play.js` 的 `pickLead`）：每題 3～4 個干擾部件（總數 6～7 張減答案數）。
   - **甲、同部件形近**：別的課本字第二層部件數一樣、**只有一塊不同**，取那一塊（清＝氵龶月 → 晴的日、精的米、猜的犭、睛的目；冷＝冫令 → 冰的水、鈴的釒、零的⻗）。學生選了，代表把這個字和那個字搞混。順序：形近字 → 同一課 → 其他課本字。答案部件裡有「上半」這種名稱的字不找甲。
   - **乙、形近部件**：長得像任一個答案部件的部件（找法同第 2 節的乙，`partLookalikes`）。
   - **搭配**：甲最多放「干擾數－1」個、留 1 個給乙（乙沒有就再放甲）；不夠用第 3 節的方法補；第 4 節的排除規則照舊。
   - 甲找到的部件剛好是那個字第一層的一塊時，筆畫從那個字切（例：日從晴切）。
   - 紀錄不改：錯誤類型照舊。題目說明下面小字標出處。
5. **檢查結果**（甲乙加入後重跑）：干擾部件 6,131 個是甲、1,654 個是乙，356 題甲乙都找不到、全用原本的方法補；全部 2,828 個（字、課）組合（有筆畫）：2,534 題用筆畫、其餘用文字；選項 6～7 張、答案部件正確、干擾部件不含這個字自己的部件、用筆畫的題目每張都切得出來、用文字的題目每張都是字型有的字。筆畫下載失敗時 2,663 題也都通過。實際玩過：選對答案部件按「送出」算答對。
