# 老師專區「一位學生」簡潔畫面（設計草稿，待討論）

2026-10-25 新增。背景：新手教學已全部刪除（`docs/history/history-2026-10-25.md`），老師只能靠畫面本身看懂；一般老師專區的前後測、字層級三項分析（`docs/design/a8-terms.md` 第 8、23 點）也要改版。**還沒動程式**，定案後再做，定案的內容整理進 `docs/design/analysis-design.md`。
回答時用題號，例如「P-1 同意；P-3 取前 5 個」。

## 一、設計原則

1. **一進來就看到答案**，不要先叫老師選四個選單。老師想問的是：這位學生有沒有進步？哪些字還不會？哪些字老是搞混？
2. **一個畫面只回答一個問題**，每張圖最多 3 個重點數字。
3. **用老師的話**，不出現統計名詞（見第四節換字表）。
4. **預設值選好**，老師不動任何選項也看得到有用的結果；細節收在「看更多」。
5. **對學生的結果不說「退步」**（沿用學生結果畫面的慣例），對老師說「比前測低，可能需要複習」。

## 二、「一位學生」畫面（預設）

```
選學生： ［小明］ ［小華］ ［小美］            範圍：最近一輪前後測 ▾

┌ 有沒有進步？ ───────────────────────────────┐
│ 前測  ●  ● ●            4 題對 2 題（50%）      │
│ 後測  ●  ●  ● ●        10 題對 8 題（80%）      │
│ ▲ 比前測高 30 個百分點                          │
│ （這次題目少，參考就好）                         │
└──────────────────────────────────────────┘

┌ 還需要加強的字 ─────────┐ ┌ 反應最慢的字 ────────┐
│ 蟲（錯 3 次）  海（錯 2 次）│ │ 營（平均 7.2 秒）…      │
└────────────────────┘ └──────────────────┘

┌ 容易搞混 ──────────────────────────────┐
│ 「努」常選成「怒」（選錯 4 次，比亂猜多）          │
└──────────────────────────────────────────┘

［看更多：每一課］［趨勢圖］［明細］［匯出 Excel］
```

### 各區塊的意思與資料來源（都是第 3 版紀錄已有的欄位）

| 區塊 | 顯示什麼 | 用哪些欄位 |
|---|---|---|
| 有沒有進步？ | 前測、後測各一排小圓點，**每個點是一次評量**（A8 第 8 點：把每個點直接列出來，不取平均）；旁邊寫「幾題對幾題」；最下面一句白話 | `prepost`、`firstCorrect`、`at`、`lesson` |
| 還需要加強的字 | 錯最多次的前 N 個字 | `char`、`firstCorrect` |
| 反應最慢的字 | 答對平均秒數最長的前 N 個字（只算有答對的） | `char`、`correctSec` |
| 容易搞混 | 選錯時最常選成的那個字，與「亂猜會佔多少」比較，明顯高於亂猜才列出 | `char`、`firstPick`、`errorType`、`options`；沿用 `teacher.js` 的 `chanceOf` 邏輯（已實作） |

- **沒有前測的課**寫「這一課沒有前測，無法比較」，不拿別課的前測湊（A8 第 12 點）。後測可以多選前面教過的課，每一課各自配對。
- **題目少的提醒**：一個點不到 3 題時，圖旁寫「這次題目少，數字容易大起大落，參考就好」（取代原本的空心點圖例）。
- **完全沒有標前測或後測的評量**：預設不放進這個區塊（A8 第 6 點：沒標的不進前後測比較），但仍可在「看更多」的趨勢圖看到。

## 三、「看更多」收起來的東西

- 每一課的前後測（原本「依課別」的長條圖）。
- 趨勢圖（折線圖，原本「依時間」）：背景色塊改成前測灰、後測藍、未標記不塗色（PR #131 已完成）。
- 逐字作答明細（原本的「看明細」和「逐字學習紀錄」）。
- 反應時間、流暢性（每分鐘認出幾個）、提示層級、間隔天數：從原本的「看什麼」選單搬進這裡，要看的老師再點。
- 匯出 Excel。
- **全班總表**維持原本的分頁（學生 × 生字，一種藍色越深越好）。
- **進階分析**維持原本的分頁（樞紐分析表）；**研究畫面要有研究計畫才出現**（A8 第 20 點），目前還沒做。

## 四、換字表（畫面上不再出現的詞）

| 原本 | 改成 |
|---|---|
| 正確率 | 第一次就答對的比例（附「幾題對幾題」） |
| 反應時間 | 答對平均幾秒 |
| 流暢性 | 每分鐘認出幾個字 |
| 樣本數不足 | 這次題目少，參考就好 |
| 錯誤類型：同詞易混／同音／形近 | 同一個詞裡的字／唸起來一樣的字／長得像的字 |
| 亂猜會佔 | 維持原本用語（2026-10-23 已定） |
| 未標記 | 沒標前測或後測 |
| 依前後測比較 | 前測和後測 |

## 五、待決（請回答題號）

| 題號 | 問題 | Claude 建議 |
|---|---|---|
| P-1 | **預設範圍**要看哪一段？ | **最近一輪前後測**（最近的前測和之後的後測）；沒有前後測時退回「本學期」。這樣一打開就是老師最常問的比較 |
| P-2 | 「有沒有進步」用百分比，還是「幾題對幾題」，或兩個都放？ | **兩個都放**：大字用「8 / 10 題」，旁邊小字百分比；不懂統計的老師看題數比看百分比直覺 |
| P-3 | 「還需要加強的字」「反應最慢的字」各列幾個？怎麼算？ | 各列前 **5** 個；常錯字至少錯 2 次才列；反應最慢只算至少答對 2 次的字（避免一次運氣影響） |
| P-4 | 「容易搞混」列出的條件？ | 沿用現有規則：實際比例是亂猜的 **1.5 倍以上、至少錯 3 次**；沒有符合的寫「看不出特別容易搞混的字，接近亂猜」 |
| P-5 | 前後測的小圓點畫法 | 每次評量一個點，**同一天考多次也分開畫**；滑鼠移上去（平板長按）顯示日期、題數；**最新的一個點放大** |
| P-6 | 「看更多」要用折疊（點開）還是另一個分頁？ | **折疊**：不離開這一頁，老師不會迷路 |
| P-7 | 練習的紀錄要不要出現在這個預設畫面？ | **不要**，預設只看正式評量；「看更多」裡可以切到練習（沿用原本的「性質」選項） |
| P-8 | 多位學生比較要不要也有簡潔版？ | **先不做**，全班總表維持原樣；等這一版老師用過再看 |

## 六、做的時候的順序（定案後）

1. 新的預設畫面（第二節），放在「一位學生」分頁最上面。
2. 原本的四個選單（看什麼／怎麼看／日期／範圍）搬進「看更多」，內容不變。
3. 換字表（第四節）一次改完。
4. 補測試（用已知答案的假資料，檢查前後測配對、沒有前測的課、題目少的提醒、三個字層級清單）。
5. 一個 PR 做完；不改紀錄格式（所有需要的欄位第 3 版已有）。
