# 老師專區「一位學生」畫面（維護者 2026-10-25 指定的版面，已做成程式）

**原則**：一般模式老師**只需要選學生**，其他都不用點按鈕挑選，**上下滑動看就好**。給不懂統計的老師看得懂，畫面簡潔。
程式在 `tools/literacy/teacher.js` 的「15b」，樣式在 `tools/literacy/index.html`（`#tSimple`）。第一版草稿（有「前測／後測比較」區塊、三項字清單、需要回答 P-1～P-8）的原文見 `docs/history/history-2026-10-25.md`。

## 一、版面（由上往下，整頁往下捲）

| 順序 | 區塊 | 內容 |
|---|---|---|
| 0 | 看誰 | 唯一的按鈕：選學生 |
| 1 | 總體紀錄（正式評量＋練習） | 五張卡：**做過**（幾次評量、幾天、幾題）、**整體正確率**（最近一天的）、**平均反應時間**（中位數）、**反應速度變化**（第一週 → 最近一週，快或慢幾秒；資料不到一週寫「資料還不到一週」）、**常見錯誤類型**（同詞／同音／形近，次數與佔錯誤的比例） |
| 2 | 每天的平均正確率 | 折線圖，一天一個點（正式評量和練習合在一起算）；有標前測、後測的那天，日期後面註明 |
| 3 | 每天的平均反應時間（越低越快） | 折線圖，一天一個點 |
| 3b | **每天的流暢性（每分鐘認出幾個字）** | 折線圖，一天一個點；只算流暢性回合（計時挑戰、流暢性模式；一個回合＝一位學生做完一次，限時內第一次就答對的字數換算成每分鐘幾個），**正式評量和練習的回合全部算**，中途結束不算；**沒有目標線，也沒有「流暢目標」這個設定**（維護者 2026-10-25）；沒有流暢性紀錄時寫「還沒有流暢性的紀錄」 |
| 4 | **各課前後測正確率** | 折線圖，每個點是一次標了前測或後測的正式評量（圓點連成線），灰色背景＝前測、藍色＝後測；**練習用橘色空心標記標在同一張圖上，不連線、不分前後測**，圖例寫明；**上面的課次按鈕可以手動點，切換看每一課**（預設「全部課合計」）；**只看一課且該生這課有教學結束日時，在教學結束、滿 1 週、2 週、1 個月後的第一次評量前畫直立線**（2026-10-25，沒評量的時段不畫，全部課合計不畫，不影響前後測）；這是整頁唯一選學生以外要點的地方，點完頁面維持原本捲到的位置 |
| 5 | 常錯的字 | 一個個小方塊：字（可以點，看那個字的每一次作答）、錯幾次、正確率；錯最多的排前面，最多 24 個 |
| 6 | 反應最慢的字 | 表格：字、詞語、課次、出現、正確率、平均反應、第一次 → 最近一次；最慢的前 10 個 |
| 7 | 容易搞混的字 | 表格：字、常選成、次數、**錯誤類型（同詞／同音／形近）**；前 10 組；錯的題目夠多時，上面多一句「特別容易選成的錯誤類型（比亂猜多）」或「接近亂猜」 |
| 8 | 近期正式評量紀錄 | **按課分組**（標題：課次、評量幾次、平均正確率），每次評量一列，欄位：日期、前後測、抽到的字、正確率（幾題對幾題與 %）、點錯、平均反應、沒有一次答對的字；只列最近 10 筆。**選項數、提示現在都固定，所以沒有單獨的欄位，只有和預設不同時才在「前後測」欄後面加小註記**（例如「後測（6 個選項）」「前測（提示：語詞挖空、圖片）」；預設＝4 個選項，正式評量與計時挑戰無提示，練習提示為語詞挖空、部件） |
| 9 | 近期練習紀錄 | 同上，「前後測」欄換成「玩法」（一般／打怪獸（合作）／生字賓果／計時挑戰）；中途結束的列出來但灰色、標「未做完」、不算進平均與總體 |

**最上面的三個分頁**（維護者 2026-10-25）：**個人／全班／進階分析**。個人＝上面這個版面（下面不再有「進階」收合區）；全班＝全班總表（不變）；**進階分析**有兩個部分，上面用兩個按鈕切換：

- **更多圖表與明細**：原本個人頁最下面「進階」裡的東西——看誰、看什麼（正確率、反應時間、流暢性、間隔、常錯字排序、高字頻生字、錯誤類型、提示層級）、怎麼看、日期、範圍、圖、明細、匯出 Excel。
- **樞紐分析**：原本的「進階分析（研究用）」，做法和內容不變（像 Excel 的樞紐分析表：選指標、列、欄、篩選，附九個範例、可存成我的比較），只是名稱不再寫「研究用」。

研究畫面要有研究計畫才出現（`docs/design/a8-terms.md` 第 20 點），還沒做；做出來時另外加，不佔用這兩個部分。

## 二、資料範圍與算法

- **統計、兩張每天折線圖、常錯的字、反應最慢的字、容易搞混的字，都是正式評量＋練習全部一起算**（維護者 2026-10-25 決定，不再只看正式評量；練習有提示與回饋、條件不固定，所以數字不能當作前後測比較）。**只有前後測是正式評量**（練習沒有前測、後測標記）。中途結束的紀錄不算統計，只在近期紀錄表灰色列出。
- 正確率＝第一次就答對的比例；反應時間＝答對題的平均秒數。
- 反應速度變化：第一天起的 7 天，對最近一天往前的 7 天；兩段都有答對的紀錄才算。
- 前測、後測標在折線圖的日期、「各課前後測正確率」折線圖和近期紀錄表；**沒有單獨的「前測 → 後測」數字比較區塊**；A8 第 8 點「每個點直接列出來」由這些做到。
- 沒有改紀錄格式；所有欄位第 3 版都有。

## 四、還可以再想的（沒有回覆也不影響使用）

- 要不要把「前測 → 後測」的比較做成一個區塊放在總體紀錄旁邊（第一版草稿有，現在拿掉了）。
- 練習的總體、折線圖要不要也有（現在只有紀錄表）。
- 常錯的字、反應最慢的字目前不分課次；多課混在一起時是否要分課。
