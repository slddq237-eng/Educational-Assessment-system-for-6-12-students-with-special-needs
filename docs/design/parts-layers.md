# 部件三層設計（2026-10-31 維護者提出，討論稿）

部件（字拆成的小塊，例如「清」＝氵＋青）以後會被六個功能讀取。這份把「部件分幾層」「每個功能讀哪一層」「新玩法怎麼用部件」寫在一起。
**目前狀態**：設計討論稿，程式還沒改；現況（平台現在怎麼讀）見 `docs/materials/materials.md`「部件資料的狀況」。新玩法 R5、R6、W3 的舊設計與待解決問題見 `literacy-play.md`「聽音補部件、聽音選部件」，這份定案後會回頭改寫那一節。

## 1. 三層定義

| 層 | 內容 | 和現在的對照 |
|---|---|---|
| 第一層 | 按結構拆成 **2～3 個可讀出聲音的部件**（例如「清」＝氵＋青；「森」＝木＋木＋木） | 取代現在的 A 欄「形符＋聲符」；**不再標形符、聲符**，A 欄的讀音比對改成只用來檢查「可讀出聲音」 |
| 第二層 | **可教學角度拆到最細**：拆到部首就停，不拆成單一筆畫或罕用字；同一部件出現幾次寫幾次 | 就是現在的 B 欄 |
| 第三層 | **開源部件（cjkvi-ids）拆到最細，只存最底層**：拼起來剛好是字，不含中間層 | 現在的「拆到最細（電腦，含中間層）」；備課分析要的「含中間層」由程式用 `prep.js` 的 `allParts` 遞迴算，不存進表格 |

規則：
- **可讀出聲音**：部件是一個字，或是部首的變體。變體對照到原來的字：氵→水、扌→手、艹→草、亻→人、忄→心、犭→犬、礻→示、衤→衣、糹→糸、釒→金、⺮→竹、灬→火、刂→刀；阝要看位置（左＝阜、右＝邑）；辶、攵、廴等其他變體之後補全，請老師確認。**遊戲不會唸出部件的讀音**，這只是產生第一層資料時的標準。
- **每層各有「電腦」和「人工手動」兩欄**（第三層只有電腦）。讀取時每層都是「人工手動 → 電腦」；老師還沒確認的電腦拆法照樣算有資料。
- **「沒有」的意思**：該層完全沒資料（例如獨體字、拆不出來）才往下一層；三層都沒有就當獨體字，照舊用切塊提示（見 `literacy-play.md` 的 `cutHtml`）。
- **足、酋不再往下拆**（2026-10-29 維護者決定）：每一層都當成一整塊。
- 人工手動欄寫「待討論」的格子標紅色、不寫進平台；表格另加「狀態」欄（已確認／待確認／待討論），不要只靠顏色。
- **舊的 `PARTS`（康軒四上 86 字人工部件）**先歸到第二層人工手動欄，狀態標「待確認」，請老師之後確認；`PARTS` 這個資料就退場，讀取統一走各層。部分字（例如串＝口 口 丨含單一筆畫）不符合第二層規則，確認時一併改。

## 2. 每個功能從哪一層開始讀

統一規則：每個功能只指定「**起點層**」，該層沒有資料就往下一層讀。

| 功能 | 起點層 |
|---|---|
| (1) 各評量的部件提示 | 第二層 → 第三層 |
| (2) 備課分析 | 老師自己選第一層／第二層／第三層（單選；複選會讓同一個字重複計入排行） |
| (3) 部件重組（R4） | 第二層 → 第三層 |
| (4) 聽音選部件 | 第二層 → 第三層 |
| (5) 聽音補部件（R5） | 第一層 → 第二層 → 第三層 |
| (6) 看部件寫字（W3） | 第一層 → 第二層 → 第三層 |

為什麼 (5)(6) 從第一層：這兩個要「遮住一塊部件」，第一層是 2～3 塊、位置單純；第二層以後常有部件包在別的部件裡面，位置不好對。
(1)(3) 現在讀的是 B（＝第二層），所以這兩項改完後畫面幾乎不變，老師已填的 23 個 B 人工手動（南一六上）照樣用到。

## 3. 三個新玩法

1. **聽音選部件**（R6；2026-10-31 維護者決定從「聽音拼部件」改名）：聽字音，從選項挑出組成這個字的部件（複選）。**全部選對才算對**（2026-10-31 維護者決定）；點選項第一次＝選取、第二次＝取消選取，學生選錯可以改。**重複部件拆出幾個就算幾個答案**：森拆出三個木，答案就是三個木（選項裡要有三張木）。選項**固定至少 6 個**，需要一個「部件選項池」挑干擾部件（形近部件優先，見 `literacy-play.md` 待解決問題 3、4）。
2. **聽音補部件**（R5）：上方顯示這個字，**遮住一塊部件**（練習隨機遮；正式評量固定，見下），其餘部件看得到；學生從 **4 個選項**（1 個答案＋3 個干擾部件）選出被遮的那一塊。兩部件的字遮一塊、露一塊；三部件的字遮一塊、露兩塊。
3. **看部件寫字**（W3）：同樣顯示遮住一塊部件的字（遮法同聽音補部件），學生寫出來。電腦判斷不出手寫對錯，要先決定怎麼記錄（見第 6 節）。

### 遮哪一塊

- **練習**：每題隨機遮一塊（2026-10-31 維護者決定）。
- **正式評量**：一律照**筆順的先後順序固定**，遮**比較晚寫到的部件**（2026-10-31 維護者決定），同一個字每次遮同一塊，評量條件才固定。三塊的字遮最晚寫的那一塊。
- 先用結構訂預設，個別字例外請老師對照教育部《國字標準字體筆順》確認：

| 第一層結構 | 預設遮的部件（晚寫的） |
|---|---|
| 左右、左中右 | 右邊那塊 |
| 上下、上中下 | 下面那塊 |
| 左上、右上、上方、左方包圍（例：病、句、問、區） | 裡面的那塊（外層先寫） |
| 左下包圍（例：道、建） | 外層（辶、廴最後寫）；**例外**：走字旁（起、超）走先寫，遮裡面 |
| 全包圍（例：國） | 裡面的那塊（囗先寫、封口最後；先照這樣，請老師確認） |
| 下方包圍、交疊、獨體字 | 還沒訂，第一版略過 |

- 程式不算筆順，**每個字的「正式評量遮哪一塊」存在資料裡**：先照上表自動填，老師可以在人工手動欄改；實作時放進部件表（步驟 2）。
- 這也算正式評量條件，R5、R6、W3 開放正式評量時要記進 `a3-conditions.md`。

### 遮蔽怎麼做

- 遮蔽要知道部件在字的哪裡，所以**平台要有每個字第一層的「結構」**（左右、上下…）。目前結構只在部件表 Excel 的「結構」欄，網頁讀不到，要隨資料步驟一起寫進 `shared/`。
- 先用 CSS 在字上蓋一塊區域，**不另外做圖檔**；先挑 5～10 個字做原型，確認全字庫正楷體畫出來的位置準不準，再決定要不要改用圖檔。
- 第一層是左右、上下、左中右、上中下的字，用長方形遮得住：2026-10-31 的部件表 2,160 字裡約 1,830 字（85%）。
- 第一層**本身**就是包圍結構的字約 222 字（11%），例如道＝辶＋首、國＝囗＋或：遮外層要遮 L 形或口字形，要另外做預設形狀；**第一版略過，第二版補**（用 `clip-path` 畫，個別字再微調）。「艇」第一層是舟＋廷（左右），不屬於包圍，不用特別處理。
- 交疊（20 字）、獨體字（86 字）略過。退到第二層也不會讓包圍字好遮（第二層的部件位置更複雜），所以遮蔽題**不退到第二層**。

## 4. 這些改動不會碰到的事
