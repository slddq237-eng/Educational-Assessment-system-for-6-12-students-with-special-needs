# 直式生字練習簿（`tools/practice/`）

2026-11-12 第一版（雛形，維護者決定的內容；為什麼這樣決定見 `decisions/2026-11-12-practice-book.md`）。寫字評量的「考卷」在 `writing-design.md`，這份是**練習用的紙本**，和考卷分開、不共用題目。

## 1. 現在是什麼

- 網頁 `tools/practice/index.html`（一個檔案，程式寫在頁面裡）；**不放進首頁**、不存任何資料、不產生作答紀錄、不連外部網站。老師選字、按「列印」，印在 A4 直式紙上給學生練習。
- 字從**課本課次**選（選課本、勾課次，自動填入寫字生字；同一個字只留一個），也可以在生字欄自己改字（非課本字也行），最多 60 個字。

## 2. 版面（維護者對照國語習作確認：欄由右到左、注音在字右邊）

一個字一欄，**欄由右到左**（第一個字在最右邊），整頁最右邊是標籤欄。每一欄由上到下是學習順序：

| 段 | 內容 |
|---|---|
| 看 | 正常的字（字形尺格子）；右邊獨立一格放注音（注音字型、置中；預設印，可取消；只給看、不用學生寫） |
| 筆順示範 | 教育部筆順圖原樣縮放（固定 7.2 公分高，一欄一張）；可關掉；沒有圖的字顯示「沒有筆順圖」 |
| 描 | 淡灰字 2 格 |
| 褪除 | 2 格：字的部件一塊一塊蓋住讓學生補寫（見第 4 節）；切不開的字改成字變淡 |
| **摺線** | 整頁一條橫的虛線，頁尾印「沿虛線往上摺，蓋住上面的字，再寫獨立練習」（遮擋與主動書寫） |
| 獨立練習 | 空的字形尺格子；預設「自動」放滿一頁，也可以選 2～10 格 |

- **格子大小**可選小（1.5 公分）、中（1.8，預設）、大（2.2），和寫字考卷一樣。一頁放幾個字：小 7、中 6、大 5；多的字自動分頁，頁尾印「第 n 頁，共 m 頁」和格子大小。
- 實測（筆順示範開／關時獨立練習格數）：小 6／10、中 4／8、大 2／6。所有組合都放得下一頁（瀏覽器量過；**還沒有實際印出來比對過**，要印一頁試摺）。
- 格子用共用的 `RulerCell`（`shared/ruler-cell.js`），字放的大小位置和 `shared/ruler.js` 量分線時一致（頁面裡的 `fit`）。

## 4. 部件褪除只能做一部分

褪除要把字切成部件，再依序蓋住：

- 用直線切（字形尺的分線）只有約 **13%** 的字切得乾淨，因為左右兩塊的筆畫常在不同高度伸進對方的範圍。
- 現在的做法：先找相連的筆畫（連通區塊），每塊歸到重心所在的部件；每一塊的筆畫 **98% 以上**要落在自己部件範圍裡才切。1,678 個左右、上下、左中右、上中下的課本生字約 **46%**（772 個）切得開；放寬到 85% 會切錯（例如「案」的「木」少上面一橫）。
- 切不開的字（部件筆畫相連，例如「案」「現」；包圍字目前全部切不開、獨體字沒有分區）改成**字變淡**（兩格濃度 50%、20%）。
- 要做到每個字都按部件褪除，需要「每一筆屬於哪個部件」的資料。教育部信已同意部件分色等功能（維持原筆畫形狀的前提下），所以**現在可以做，只是還沒做**：要取得筆畫座標資料、把筆畫分給部件（`parts-strokes.md` 第 4 節、路線圖 E17）。
- 以上比例是用全字庫正楷體在瀏覽器裡算的，只看畫面、沒逐字人工檢查。

## 5. 注音要不要印

預設印、可取消。擔心抄寫時還要寫注音、工作記憶負荷太大，所以**注音只印在「看」旁邊，不放進描、褪除、獨立練習的格子，也不要學生寫**。文獻查了中英文共 6 組搜尋，沒有找到直接比較「抄寫時有沒有注音」的研究，只有間接證據（課綱把「運用注音符號輔助識字」列為低年級目標；初學者看得到拼音就會去看；手寫比只打拼音更能提升書寫表現；認知負荷理論的冗餘效應與專長反轉效應是成人與多媒體研究），詳細在 `plans/roadmap-plans.md`「寫字學習單」。想知道哪種比較有效要自己做兩版比較（不急）。
