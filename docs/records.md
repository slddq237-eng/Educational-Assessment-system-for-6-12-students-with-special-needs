### A8 名詞與時期定義（2026-10-21 草案，討論中）
完整內容在規格書「階段 A 討論資料 → A8」。**優先序高（階段 A）：名詞會寫進每一筆作答紀錄，要在試用老師（B4）開始收資料前定好。**重點：
- **為什麼**：系統把三套名詞混在一起。每課自動判斷的「時期」是基線期、教學中、教學後、維持期，研究名詞和教學用語混用，而且其實是在判斷「這課教過沒」；學扶卡片又把前測、後測硬套成時期。名詞會寫進每一筆紀錄，之後的一般／進階／研究三種檢視（C1）都要用。
- **文獻查證**：前測／後測是老師日常用語，也是「單組前後測設計」（前實驗設計，只比兩個時間點）。單一受試研究依「有沒有在介入」分基線期（A）、介入期（B，也稱處理期）、維持期，每期要多筆資料（WWC 至少 3 筆、5 筆以上完全符合）；介入結束當節的後測是介入期的最後一筆。RTI 用篩選、進展監控。維護者的理解經查證正確。
- **三個概念**：課程進度（教學前／中／後）、評量用途（平常／前測／後測）、研究時期（基線期／介入期／維持期，研究者事先定）。
- **資料三層、單向相容**：練習 → 一般評量 → 研究評量。研究資料可以併進一般統計（基線期→教學前／前測；介入期→教學中；介入期最後一次→後測；維持期→教學後（追蹤）），一般資料不能被當成研究時期。
- **名詞對照總表**（規格書 A8「名詞對照總表：一般模式 ↔ 研究模式」）：表 1 研究時期與探試類型併進一般統計時算成什麼（基線期的初始探試、介入前補測、未教層的例行探試→教學前／前測；介入期→教學中；介入期最後一次→後測；維持期→教學後（追蹤）；類化探試→另列、不併進正確率主線）；表 2 哪些資料可以進一般統計、哪些可以進研究分析；表 3 分析名詞的一般說法和研究說法。換算要寫成程式裡的一張對照表，三種畫面共用。注意：「學會」的精熟標準還沒統一（研究方法規格書寫連續 3 次 90%，簡報草案寫連續兩次 80%）。
- **程式原則（草案）**：紀錄存事實（正式或練習、用途、日期、教完第幾天；研究另存計畫代號和當時時期），名稱在顯示時才決定；研究資料要在作答前標好；舊紀錄照原樣保留、顯示時換算。
- **和 `docs/research-method-spec.md` 的關係**：那份的主設計「跨行為多探試」是每一課各自依教學日期分基線、介入、維持；系統現在「每課依教學日期自動判斷時期」本質上對應這個設計，只是名稱混用。要算研究資料，還需要教學日期在介入前就記好、條件固定、每期筆數夠。A8 定案後兩份文件的用詞要一起對齊（那份也用「後測」）。
- **維護者傾向（2026-10-23，待夥伴確認，還不算定案）**：
  1. 多筆前測：一般畫面用平均，研究畫面每一點都畫出來（規格書表 1「取哪一筆」）。
  2. 研究計畫多細：一位學生可以同時參加好幾個研究計畫，每筆紀錄記它屬於哪個計畫（以後不用再改紀錄格式）。
  3. 期中檢測：就叫「教學中」，不另外取名。
  4. 「學會」標準：A8 只定「紀錄要存當時用的標準」，80% 或 90% 在 A3 決定。
- **待討論**：研究時期是「依每課教學日期推算」還是「另建研究計畫指定」（或兩者並存，Claude 建議並存：平常推算叫「課程進度」，有研究計畫的資料才有「研究時期」）、前後測的單位（一課或一段學扶課程；Claude 建議每次施測由老師勾選、紀錄存「前後測代號」）、能不能事後把舊資料標成基線期（原則上不行）、三種畫面誰看得到（Claude 建議預設只開一般，進階在設定打開，研究要有研究計畫才出現）、一般畫面的時期名稱（Claude 建議教學前／教學中／教學後／追蹤）、對應表的兩處調整（介入期只有研究者標記的最後一筆算後測、其餘算教學中；維持期算「教學後（追蹤）」不算後測；Claude 建議都同意）。
- **決定方式：中間路線**（2026-10-21 維護者同意）：分清楚「很難改的」（存進資料的東西：紀錄記哪些事實、教學日期怎麼存、研究資料怎麼標記）和「很容易改的」（畫面上的名詞、圖表、研究設計範本、分析指標）。現在一次定好：一般和進階模式的名詞與畫面；研究模式只定地基（紀錄存事實、教學日期可每位學生各自設定、研究資料作答前就標好、單向相容、研究計畫開始收資料後鎖定、改只能開新版本）；所有名稱集中在一張對照表。研究模式的內容（研究畫面用詞、預設研究設計、分析指標、研究計畫畫面）之後再補，規格書對照總表的研究欄標成「暫定」。
- **研究模式的架構準備**（2026-10-21 檢查現有程式）：沒有「以後做不到」的地方（研究設計範本、層用課次或字組、研究計畫存檔分享、舊資料不會被誤當研究資料、當時的條件都查得到）。要先處理的三件事：

  2. 紀錄存的是作答當下判斷好的時期名稱（`phase`），老師專區的時期圖直接用它；只有趨勢圖「橫軸：教學開始後第幾天」是用**現在的**教學日期回頭算（`teacher.js` 的 `trendView`），教學日期改過，這張圖的位置就會跟著變（2026-10-23 對照程式更正說法）→ 紀錄存事實（含當時用的教學日期版本），顯示時由一張對照表換算。和 A8 定案、前後測卡片、紀錄格式第 3 版一起做。
  3. 研究計畫要能鎖定和留版本 → 先定規則（開始收資料後鎖定、改只能開新版本），做法沿用字組的鎖定機制。

- **教學日期的修改：修正錯誤 vs 計畫變更**（2026-10-21 維護者提出）：改日期不會多出一筆作答紀錄。但只存「作答當下的日期」的話，修正打錯的日期後舊紀錄會前後不一致，所以分兩種：「修正錯誤」（例如 10/5 打成 10/15）連舊紀錄一起套用；「計畫變更」（真的延後開始）舊紀錄維持原樣。做法：教學日期有自己的修改紀錄（哪天改、從什麼改成什麼、哪一種）；改日期時問老師是哪一種；作答紀錄存當時用的教學日期版本。一般、進階畫面用修正後的日期；研究畫面鎖定後仍可修正，但修改紀錄要顯示出來，計畫變更則開新版本的研究計畫。
- **連帶變更（A8 定案後一起做，紀錄格式只升級一次到第 3 版）**：學扶卡片改名「前後測」、只分前測和後測、條件和小考檢測一樣、紀錄加「前後測」欄；時期名稱改用定案的用詞（集中在一張對照表）；紀錄存事實（含當時用的教學日期版本）；教學日期加修改紀錄與「修正／變更」選擇。教學日期可每位學生各自設定，要在試用老師開始前做。
