# 部件表用 Google 試算表給老師共編：操作清單（2026-10-31）

把 `docs/materials/parts-table.xlsx` 上傳成 Google 試算表，讓老師線上共編，填完下載回 xlsx 交給 Claude。表裡每欄的意思、怎麼填，見表內「填寫說明」頁；部件三層設計見 `docs/design/parts-layers.md`。

**已驗證**（2026-10-31）：xlsx 上傳 Google 試算表再下載，三個分頁的內容 0 格不同，下拉選單、凍結窗格、篩選、底色都保留；`make_parts_columns.py` 能正常讀、重新產生的 `shared/parts-layers.js` 和 repo 的版本逐位元組相同。**還沒驗證**：老師實際填了內容之後下載，程式讀得對不對，所以先請老師填 20～30 個字傳給 Claude 測一次，再全面開工。

## 一、維護者上傳

1. Google 雲端硬碟「新增 → 上傳檔案」，選 repo 裡最新的 `docs/materials/parts-table.xlsx`。
2. 在檔案上按右鍵，「開啟方式 → Google 試算表」（會轉成試算表，原本的 xlsx 不受影響）。
3. 標題寫成「部件表（基於 ○○，日期）」。○○＝這份 xlsx 在 repo 最後一次修改的 commit 編號（用 `git log -1 --format=%h -- docs/materials/parts-table.xlsx` 查；2026-10-31 是 `6fadca3`）。之後合併時靠它對版本。
4. 確認三個分頁都在：生字部件、填寫說明、部首變體對照。

## 二、鎖住老師不該改的欄位

電腦算的欄位（白底或黃底）每次執行 `make_parts_columns.py` 都會整欄重算，老師改了會被蓋掉。

1. 「資料 → 保護工作表和範圍」，選「工作表」，設定權限選「自訂」，只勾維護者自己。
2. 在「生字部件」分頁排除綠色欄位：D（老師修正：結構）、F（第一層人工手動）、G（第一層狀態）、I（第二層人工手動）、J（第二層狀態）、M（遮第幾塊人工手動）、O（備註）。
3. 「部首變體對照」分頁只開放 B（對照成）和 D（老師確認）。
4. 「填寫說明」分頁整頁保護，只有維護者能改。

## 三、分享給老師

1. 「共用」輸入每位老師的 Google 帳號，權限「編輯者」。
2. 「一般存取權」設成「限制」，**不要**開「知道連結的人都能存取」（表裡有課本生字和課次）。
3. 關掉「編輯者可以變更權限及共用設定」。

## 四、分工

1. 先決定每位老師負責的列範圍（例如 2～500、501～1000），寫在通知老師的訊息裡，範圍不要重疊。
2. 老師用「資料 → 建立篩選器檢視」只看自己那一段。同一格被兩個人同時改，以最後存的為準，不會提醒衝突。

## 五、請老師這樣填

1. 先讀「填寫說明」分頁，重點是「要補哪些字的第一層」那一列：篩選「結構」不是「獨體字」且「第一層（電腦）」空白的字，約 214 個。
2. 在「第一層（人工手動）」填部件；狀態用下拉選單選（已確認、待確認、待討論），不要自己打字。
3. 部件讀不出聲音時，先到「部首變體對照」分頁補「對照成」。
4. 筆順不是先左後右、先上後下的字，在「正式評量遮第幾塊（人工手動）」選 1、2、3。包圍字不看筆順，不用確認。
5. 不確定的字，狀態選「待討論」，並在「備註」寫原因。
6. 不要把學生姓名、照片、成績寫進這份表。

## 六、共編期間

1. repo 裡的 `parts-table.xlsx` 先不要改。夥伴或 Claude 要匯入新課本、改教材時，先通知維護者，Claude 再把老師填的綠色欄位合併進新版。
2. 先請老師填 20～30 個字，下載傳給 Claude 測一次，通過再全面開工。

## 七、收回來

1. 老師填完，維護者「檔案 → 下載 → Microsoft Excel (.xlsx)」。
2. 把下載的檔案交給 Claude，不要自己放進 repo。
3. Claude 先在暫存資料夾跑 `make_parts_columns.py`（需先下載 cjkvi-ids 的 ids.txt、pinyin-data 的 pinyin.txt，不放進 repo；用法見該程式開頭說明）和 `node docs/scripts/check.js`。
4. 沒問題後，Claude 開 `claude/` 分支和 PR，PR 說明寫誰填了哪些字、有哪些「待討論」。
5. `shared/`、`docs/` 是共用檔案：先告知夥伴，要擁有者（slddq237-eng）同意才合併。

## 八、收尾

1. PR 合併後，把試算表的分享權限改成「檢視者」或停止共用，避免有人繼續改而和 repo 對不上。
2. 下一輪要填時，從 repo 最新的 `parts-table.xlsx` 重新上傳，不沿用舊試算表。
