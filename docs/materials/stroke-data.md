### 筆畫座標資料：用 g0v zh-stroke-data（維護者 2026-11-14 決定可以用，還沒下載）

之後做部件切分、軌跡比對要每一筆的座標。維護者決定用 g0v 的 zh-stroke-data（https://github.com/g0v/zh-stroke-data，本機試驗用過，`../design/parts-strokes.md` 第 2 節）。2026-11-14 讀它的 README，**頁面上寫的**是：

- **來源**：教育部「常用國字標準字體筆順學習網」（寫的是「常用」，我們的圖包是「國字標準字體筆順學習網」6,063 字；兩邊收錄的字不一定一樣），README 寫「著作權係中華民國教育部所有」，目的是「提供本部標準楷體字之筆順教學利用，不得用於商業用途」。
- **格式**：標題寫「常用國字標準字體筆劃 XML 資料檔」，用 `fetch.go` 從網站抓 XML，再用 `stroke2json.sh` 轉成 JSON（repo 有 `json/` 資料夾）；檔名依 Unicode 編碼。README **沒寫**座標格式、每個字的檔案大小、收錄幾字、缺哪些字（本機試驗發現缺「乃」「粄」）。
- **授權**：**沒有 LICENSE 檔，README 也沒寫資料或程式碼的授權**。README 自己的說法是 XML 筆劃資料「不屬於教育部上述授權範圍，而是自網頁版自行取得，為非營利之教育目的，依著作權法第 50 條」；其餘檔案由作者宣告貢獻到公眾領域。**沒有提到創用 CC。**
- **有 `missing/` 資料夾**：README 寫那是「從數個字中挑選出個別筆畫，變形後組合出新字」——**g0v 自己組出來的字，不是教育部的筆畫**。

怎麼用才符合教育部回信的條件：

1. **授權的依據是教育部回信，不是 g0v。** g0v 沒有授權聲明，它只是把教育部網站上的同一份筆畫資料整理成 JSON；我們使用這份資料的條件是教育部回信的條件（原筆畫形狀、免費無廣告、標明出處，第 3 節）。出處寫「教育部《國字標準字體筆順學習網》」為主，再註明「經 g0v zh-stroke-data 整理」。
2. **不能用 `missing/`**：變形、組合出新字形違反「不變形、不創造新字形」。放進 repo 時排除這個資料夾；用到的字如果只有 `missing/` 有，就當成沒有筆畫資料。
3. **放進 repo 前先下載確認**：真正的座標格式、每字大小、全部加起來多大（和圖片 17.5 MB 相比）、收錄哪些字、課本寫字生字缺哪些；並和圖片對照（同一個字的筆畫數、筆順一致）。
4. 非商業的限制照教育部回信，資料夾要像 `shared/stroke/` 一樣寫授權說明。
5. 以上都是從 README 讀到的，**沒有實際下載檔案檢查**。

- 回信內容（重點，不是逐字全文）：

### 維護者的理解（2026-11-13）

教育部的意思是**可以用、可以放到平台上**；我們**目前的作法不是改作，不用另外取得授權**；**要標示出處**。

這是維護者對回信的理解，下面分開寫「信的原文有寫」和「是判斷」，之後有疑慮才知道要問什麼：

| | 信的原文有寫 | 判斷（沒有逐字寫） |
|---|---|---|
| 使用方式 | 格式轉換、部件分色、拼圖互動、軌跡比對（維持原筆畫形狀與筆順）；公益特教教學目的 | — |
| 放在平台上 | 「即可依您規劃之方式進行教學利用，無須另行辦理專案授權」 | 把圖放在公開的 GitHub repo、讓別人下載：依創用 CC 姓名標示－非商業性－禁止改作本來就允許「原樣散布」（要標出處、不商用） |
| 把部件的筆畫隱藏（褪除、聽音補部件不畫被遮的筆畫） | — | 和「部件分色、拼圖互動」同一類（不改筆畫形狀） |
| 逐筆動畫 | — | 同上（網站本身就有筆順動畫，我們不改它的筆畫） |
| 現在的練習簿 | — | 圖片原樣顯示、只縮放，沒有改筆畫形狀，不是改作 |

| 維持原筆畫形狀與標準筆順，不變形、不創造新字形 | 圖原樣複製，頁面只等比例縮放；`check.js` 只放行 `shared/stroke/` 的 png | 部件切分、褪除、上色都不能改筆畫形狀；不能拿字型或手繪的字當筆順；不用 AI 重畫 |
