# 想法的輕重緩急：難改／好改／不急（2026-11-02 新增）

`roadmap.md`「新想法怎麼排」的補充。不用懂程式也能用，AI 排序時也照這個分。

**一個問題：**這個決定以後改，會不會讓已存的資料或已公開的東西作廢？**

| 類型 | 例子 | 怎麼處理 |
|---|---|---|
| **難改** | 作答紀錄格式、學生代號、儲存名稱、正式評量條件（A3、A8）、授權版權 | 現在想清楚，先討論再動手，定案後寫一則 `docs/decisions/` |
| **好改** | 畫面、按鈕位置、遊戲玩法、文件怎麼分 | 想到就記，要做時再做 |
| **不急** | 新的遊戲化功能、換框架、後端 | 記進後面的階段，先不做 |

老師用不下去的錯誤、會讓已存資料作廢的問題，隨時做。想法多時全部先記進 `docs/plans/pending.md`，每月初請 AI 依此表分類，只挑一件「做」，難改的先看。
