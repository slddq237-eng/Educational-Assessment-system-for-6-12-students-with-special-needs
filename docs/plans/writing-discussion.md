## 項目 1：每題記什麼（① 級，會寫進作答紀錄；⏸️ 2026-11-07 移到第 3 版再定）

**2026-11-07 維護者決定紙本不登錄**，所以下面「第 1 版的選項」用不到；第 3 版線上書寫開工前，依下面「程式能判斷嗎」那張表重新設計（錯誤類型改成程式自動判斷，照結構、筆畫、部件、筆順分組的想法保留）。以下原文保留給第 3 版參考。

**現在**：識字題每題一筆紀錄，記「第一次就答對」（`firstCorrect`）、反應秒數等。寫字沒有反應秒數，對錯要靠老師改。

**維護者問：錯誤類型能不能讓程式判斷？**（Claude 2026-11-07 說明）
- **紙本（第 1、2 版）不行**：學生寫在紙上，程式看不到字，只能老師看了再勾。筆順在紙上也看不出來（除非老師在旁邊看著寫），所以紙本不記筆順。
- **線上書寫（第 3 版，見項目 5）大部分可以**：學生在平板上寫，程式拿得到每一筆的位置和先後順序，和標準字比對：
  | 分析面向 | 程式能判斷嗎 | 怎麼判斷 |
  |---|---|---|
  | 筆畫（缺筆、多筆） | ✅ 容易 | 數筆畫數，和標準筆畫數比 |
  | 筆順 | ✅ 可行 | 每一筆的方向、先後和標準筆順比 |
  | 整體結構（部件位置、比例） | ✅ 大致可行 | 每個部件的筆畫寫在字的哪一塊，和標準位置比（部件表已有「左右、上下、包圍」等結構） |
  | 部件錯用、替代（例如「蜂」寫成「峰」） | 🔶 部分可行 | 要電腦「認出寫的是哪個部件」。任意認字很難；但只在**這個字的形近部件**幾個候選裡比「最像哪一個」，做得到，準確率要實測。需要形近部件表（E4 也要用） |
- **前提是台灣的標準筆順、筆畫資料**：這份資料來自教育部筆順學習網，授權是「禁止改作」，比對筆畫算不算改作要問清楚；維護者正在申請的教育部書面同意（E17，`parts-strokes.md` 第 3 節）申請時建議**一併寫進「手寫評分比對」這個用途**。網路上開放的筆順資料（例如大陸做的 Make Me a Hanzi）筆順和台灣標準不同，不能直接用。⚠️ 這是授權問題，第 3 版開工前一定要先解決。

**所以第 1 版的選項（錯誤類型照分析面向分組，紙本和線上之後能放在同一張分析表）**：
| 選項 | 每題記什麼 | 老師登錄一題要點幾下 |
|---|---|---|
| A 只記對錯 | 對／錯 | 1 下 |
| **B 對錯＋照分析面向分組的錯誤類型（建議）** | 對／錯；錯的話可以再勾（可複選、可不勾）：**結構**（部件位置錯、比例不對）、**筆畫**（少筆畫、多筆畫）、**部件**（部件寫錯或用別的部件替代）、**整字**（寫不出來、寫成別的字）。紙本不勾筆順；線上書寫時程式自動填，另外多「筆順」一類 | 對的 1 下；錯的 1～3 下 |
| C 三級給分 | 全對／部分對／不會 | 1 下 |

**建議 B 的原因**：特教老師最想知道的是「錯在哪裡」（例如總是結構錯、還是常少筆畫），只記對錯看不出來；照分析面向分組，老師專區就能算「整體結構正確率」「筆畫正確率」「部件正確率」（線上書寫再加「筆順正確率」），紙本和線上用同一套分類，資料接得起來。錯誤類型可以不勾，趕時間時和 A 一樣快。C 的「部分對」每位老師標準不同，資料不好比較。
**要一起定**：錯誤類型的清單（上面是草案，請實際改考卷的老師增刪）；要不要另加一格「寫成什麼字」（打字，可留空）。
**之後才算得出的正確率要注意**：老師沒勾錯誤類型的錯題，算各面向正確率時要排除，不能當成「那一面向是對的」。

## 項目 2：寫字的紀錄放在哪裡（① 級，會影響老師專區；⏸️ 2026-11-07 移到第 3 版再定）

紙本不登錄，第 1、2 版沒有寫字紀錄；第 3 版有程式判斷的紀錄時再定（維護者傾向 C）。

| 選項 | 內容 |
|---|---|
| A 另外一份紀錄 | 寫字有自己的資料庫和 Excel，和識字完全分開 |
| B 同一份紀錄、同樣的欄位 | 和識字放在一起，每題一筆；`goal` 欄是 W1～W3 就分得出來；只加項目 1 需要的新欄位，沒有的欄位（反應秒數、選項）留空 |
| **C 同 B，老師專區分開顯示（建議）** | 同 B；老師專區、Excel 可以用「識字／寫字」篩選，圖表不把兩種的正確率混在一起算 |

**建議 C 的原因**：同一位學生「認得」和「寫得出來」放在一起比，最有教學意義（例如認得但寫不出來）；分開存就比不了。只加新欄位不用升紀錄版本，舊紀錄不受影響。但寫字的正確率通常比識字低很多，混在一起算平均會失真，所以畫面上要分開。

**維護者 2026-11-07**：選 C，分開算；之後另外做一個分析頁，比較同一位學生識字和寫字的差異（例如同一個字的識字正確率和寫字正確率）。這個比較頁放進之後的「國語分析頁」（項目 4、路線圖 C5）。選 C 才做得到，所以這個需求也支持 C。

## 項目 3：寫字有沒有「正式評量」（① 級，影響學習分析，屬 A3；⏸️ 2026-11-07 移到第 3 版再定）

紙本不登錄，第 1、2 版沒有成績，所以沒有正式評量；第 3 版再討論。

**現在**：識字的正式評量條件固定（不提示、題數一課的量等，見 `a3-conditions.md`），結果列入學習分析；練習另外統計。A9 已定「預排考試」不做正式評量。
| 選項 | 內容 |
|---|---|
| A 寫字全部算練習 | 不列入學習分析，最簡單；但前後測比不了寫字 |
| B 第一版就有正式評量 | 要先訂寫字的正式條件（題數、能不能看注音、能不能用結構提示、誰改、改的標準） |
| **C 先全部算練習，A3 再討論（建議）** | 第一版先算練習，讓老師先用、累積改考卷的經驗；要做前後測時，再把寫字的正式條件排進 A3 |

**建議 C 的原因**：寫字由老師改，改的標準（例如筆畫出頭算不算錯）沒定之前，正式評量的資料不可靠；先當練習用不會留下難改的資料。

**維護者 2026-11-07**：先選 C，同日決定紙本不登錄後，移到第 3 版再定。

## 項目 4：入口怎麼分（② 級，✅ 2026-11-07 維護者決定 B）

| 選項 | 內容 |
|---|---|
| A 不分 | 照現在，在識字評量第 1 步選目標時，右邊「寫字」那一欄點 W1～W3 |
| **B 首頁兩個入口、背後共用（建議）** | 首頁放「識字評量」「寫字評量」兩張卡片；點寫字只顯示寫字用得到的設定；學生名單、課本、作答紀錄、貼紙共用 |
| C 完全分開 | 另做一個獨立工具，自己的學生名單和紀錄 |

**建議 B 的原因**：老師覺得是兩個工具，畫面不會出現用不到的選項；資料不分家（見項目 2）。C 要把學生名單、課本、紀錄、老師專區都複製一份。
**做的順序**：先在識字評量裡把寫字做出來（項目 5～7），能用了再和 D9 首頁分類一起做入口；入口不先做，免得點進去沒東西。

**✅ 2026-11-07 維護者決定 B**。另外：**之後分析頁也獨立拉出來，做成首頁的一張卡片「國語分析頁」**，裡面可以切換只看識字、只看寫字、兩者比較（項目 2 的比較頁）等，細節之後再規劃（路線圖 C5）。現在老師專區在識字評量裡面，拉出來時要決定老師專區留下哪些。

## 項目 6：要不要登錄（② 級，✅ 2026-11-07 維護者決定：紙本不登錄）

**決定**：**老師不需要登錄紙本寫字成績**，第 1、2 版就是「出題工具」，老師自己在紙上改，系統不留成績。第 1 版**也不記出過哪些題目**（不留「哪天給哪些學生考了哪些字」），老師實際用了覺得需要再加。
- 寫字的成績和分析只在第 3 版線上書寫才有（程式自動判斷），所以國語分析頁（C5）的「識字、寫字比較」要等第 3 版。
- 好處：第 1 版不改作答紀錄格式，可以比較快開工。

**以前怎麼想**（同日）：先決定「登錄是選用的，老師自己決定要不要登錄，要登錄就考完一次登錄」，並追加小問題 6-1「不登錄時要不要留出過的考試清單」（建議留）；維護者考慮後認為老師不需要登錄，改成紙本不登錄、第 1 版也不記題目。

## 項目 7：寫字的設定步驟（② 級，✅ 2026-11-07 維護者決定）

**現在**：識字有 4 步（選目標和評量方式、選學生和課次、選作答方式、選玩法和主題）。
**決定**：
- **紙本（第 1、2 版）用 3 步**：① 選目標（W1～W3）② 選學生和課次（題數）③ 出題設定（要不要顯示注音、要不要結構提示 E9、每題停幾秒或老師按「下一題」）。**沒有作答方式、玩法、主題、貼紙**（老師出紙本卷，用不到）。
- **線上書寫（第 3 版）保留主題和貼紙**，怎麼放之後再規劃（例如答完才發貼紙、書寫畫面要不要換主題顏色）。
