# 扭蛋機（拉拉桿揭曉貼紙）、四種星等的特效和聲音

- 日期：2026-10-24
- 動到哪裡：識字評量、共用樣式、文件
- 改了什麼：做完後每位學生一台滿版的扭蛋機（轉動 → 掉出 → 搖三下 → 依星等鋪陳 → 打開，普通約 5 秒、傳說約 9 秒；拉桿是看得到的一根桿子，可以拉也可以點），拉拉桿（拖或點）或跳過；普通、稀有、極稀有、傳說各有不同的特效和合成聲音；旁邊有「？抽中機會」；正式評量也一樣；海洋、恐龍遊戲結尾改成不暴雷（神秘大魚剪影、蛋裂開只看到「？」）；「正式評量也使用主題和貼紙」開關保留、預設開並寫明要從基線期起維持
