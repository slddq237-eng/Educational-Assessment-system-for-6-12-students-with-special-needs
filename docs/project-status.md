## 3. 識字評量的設計（已定案）

### 評量目標（學習階段，建議順序但不強制）
| 目標 | 內容 | 狀態 |
|---|---|---|
| 1 聽音選圖 | 音 ↔ 義：聽語詞選圖片 | 第 2 版 |
| 2 看字選圖 | 形 ↔ 義：看字選圖片 | 第 2 版 |
| 3 形音辨識 | 聽「努力的努」，從同詞易混字、同音字、形近字中選出目標字 | **已完成** |
| 4-1 部件重組 | 看拆開的部件選字 | 第 3 版 |
| 4-2 看提示書寫 | 先用紙筆作答、老師登錄；自動評分之後再評估 | 第 4 版 |

### 正式評量 vs 練習（兼顧遊戲性與研究嚴謹度）
- **正式評量**：條件固定（選項數、提示、答錯規則都用「評量設定」的標準），出題為**純平均隨機**，結果納入學習分析。基線期固定無提示。
- **練習**：選項數、提示、答錯規則可自由調整；平均隨機時加入 **20% 常用字**（字頻最高的字，提高動機與成功經驗），結果另外統計。
- 20% 常用字**只用在練習**：放進正式評量會墊高正確率（內容效度）並造成測驗練習效應。紀錄有「常用字加題」欄位可篩除。
- 正式評量的出題方式固定平均隨機；常錯優先、字頻優先只開放給練習，且只有題數 ≠ 一課的量時才出現選項。
- 增強物（之後做）在正式評量依「完成題數」給、不論對錯；練習可依答對給。增強只出現在題目之間。

### 提示
- 層級 0 無提示；1 語詞挖空、句子；2 圖片、聲音；3 部件、遮擋字、字形；4～7 老師按鈕（口語、示範、肢體、完全提示）。
- 答錯規則（標準）：錯 1 打叉 → 錯 2、3 出下一個提示 → 錯 4 顯示答案並記為未通過。沒有資料的提示自動跳過。

### 評量時機（每位學生 × 每一課分別判斷）
1. 該課有教學日期 → 依日期：開始前＝基線期、期間＝教學中、結束後未滿 N 天＝教學後、之後＝維持期（N 預設 7）。
2. 沒有日期 → 比較學生「學習年級」與課本年級學期：還沒學到＝基線期；差 1 學期＝上學期學過；差 2～3＝上學年學過（皆為維持期）；本學期的課需老師輸入日期或按「還沒教」。
3. 學習年級＝有勾「課程調整（重整）」就用調整後年級，否則用目前年級。年級每年 8 月自動升級；8～1 月上學期、2～7 月下學期。
4. 學生可選填「本學期教學安排」：原班、資源班（抽離／外加）、學習扶助的每週節數與各自的開始日期，每學期一筆，用於比較介入前後。

### 畫面
- **快速開始（預設）**：今天要做什麼（課堂練習／小考檢測／計時挑戰）→ 誰要做 → 練哪幾課 → 開始。不出現術語，不要求評量時機。
- **進階設定**：六步驟完整版。系統記住這台電腦上次用的模式。
- **學生看得到的畫面一律顯示姓名**（輪到誰、結果、貼紙簿），沒填姓名才顯示代號；學生名單的姓名欄改為建議必填。老師畫面顯示「姓名（代號）」。姓名只存在這台電腦的瀏覽器，不進 repo。（2026-10-20 定案）

## 3-1. 賓果整合與增強系統（2026-10-20 定案）

夥伴已同意：生字賓果的玩法、主題、頭像、貼紙簿整合進識字評量。**不匯入賓果舊紀錄**，全部改用識字評量的紀錄格式。賓果在整合完成、夥伴試玩同意前照常使用，`tools/bingo/` 不修改。

- **主題**：海洋、太空、恐龍、甜點 4 個主題（＋無主題）變成所有評量共用的外觀，從賓果抽出放到 `shared/themes.js`、`shared/themes.css`。
- **主題只換外觀**：選項字大小、對比、位置、計時起點、提示、答錯規則和無主題時完全相同。
- **正式評量從基線期就套用主題與貼紙，全程不變**：避免「教學後才加入遊戲」和教學效果混在一起（單一受試研究的混淆）。學生可以自己挑主題，每筆紀錄記下 `theme`。
- **正式評量不播動畫**：作答中沒有背景粒子、怪獸動畫；題目間等待時間不變；流暢性模式只換配色。
- **增強規則**：正式評量**每完成一次評量抽一次**（不論對錯）；練習也是每次一抽，另可依答對或連線加抽。抽獎一律在結果畫面。每次給了什麼記入紀錄。
- **收藏以學生為單位**：平台共用模組（`shared/rewards.js`），用 IndexedDB 另開資料庫，以學生代號為鍵，存貼紙收藏與頭像。同網站的其他工具之後也能發貼紙。備份檔要一起包含。
- **頭像預設卡通角色，照片上傳為選填**：有需要的老師可以上傳（照片只存在老師電腦，隨備份檔保存）。改用線上資料庫前要重新評估照片是否上傳。
- **學生名單**：以識字評量的名單為平台名單（解決「名單是否共用」的待決問題）。
- **只放練習的玩法**：合作打怪獸（多人共用一張卡）、賓果連線慶祝。全課賓果卡的「版面」可當正式評量的選項方式，但不播連線動畫。
- **注音字型**：用原始字型（ButTaiwan/bpmfvs）依 `shared/lessons.js` 全部字＋干擾字重新產生子集，獨立存成 `shared/fonts/`；破音字讀音表一起補。

## 3-2. 老師專區（分析）設計（2026-10-20 定案）

參考賓果老師專區的呈現方式（數字卡、折線圖、常錯字、容易搞混的字、字的精熟歷程表），但依識字評量的紀錄格式重新做。**不一次攤開所有數據，用選單逐步選，每次只顯示一張圖或一張表＋上方 3 個重點數字**，明細按「看明細」才展開。

| 選單 | 選項 |
|---|---|
| 1 看誰 | 一位學生（預設）；多位學生比較（全班總表：學生 × 生字，格子顯示正確率） |
| 2 怎麼看 | 依時間（橫軸選「測驗日期」或「教學時間」＝教學開始後第幾天，對齊各課教學日期）；依課別；依時期比較（基線期／教學中／教學後／維持期並排） |
| 3 範圍 | 本學期（預設）、上學期、自訂起訖日期、某一時期；另可篩正式評量（預設）或練習、評量目標、課次 |
| 4 看什麼（一次一個） | 錯誤率（正確率）、反應時間、流暢性（每分鐘正確數）、間隔（教學後天數、距上次評量天數）、常錯字排序、高字頻生字（常用字）錯誤率、錯誤類型、提示層級 |

- 選單只顯示合理的組合：趨勢類（正確率、反應時間、流暢性）畫折線圖；排序類（常錯字、錯誤類型、高字頻）顯示排序表。
- 依時間的折線圖：虛線分隔各時期，並標出教學安排（原班／資源班／學習扶助）的開始日；流暢性可畫目標線。
- **逐字學習紀錄**：任何畫面點一個字，就看到那個字的每次作答（日期、時期、目標、對錯、秒數、選錯成哪個字、提示層級、當時的時期）。
- 目前畫面的資料可以匯出 Excel。
- 高字頻生字錯誤率需要先有字頻資料（維護者之後提供）；沒有資料時這個選項先不出現。
- **分析與比較一律用時期（基線期／教學中／教學後／維持期）判斷。**（2026-10-20 定案）
- **學習階段（獲得／流暢／精熟／維持）保留為簡單的效果檢核**：老師專區基本頁面有一張「學習成效一覽」，每個字標出已達習得、精熟、維持或還沒達到，讓老師大略瀏覽；不放進進階比較。判斷標準待討論（見待決問題）。
- **間隔兩種都要**：教學後天數（該課教學結束到這次評量）、距上次評量天數（同一學生同一字）。

### 進階比較（研究用，平常收起來）

給有研究需求的老師做交叉比對。放在老師專區的「進階比較」分頁，一般老師不會看到。做法是「樞紐分析表」（像 Excel 的樞紐分析：選要比什麼、依什麼分組，系統算出每一格的數字）。

| 設定 | 可以選 |
|---|---|
| 指標（一次一個或多個） | 錯誤率、反應時間（第一次作答／答對秒數）、流暢性、間隔、常錯字排序、高字頻生字錯誤率、錯誤類型分布、提示層級 |
| 列（第 1 個分組） | 字、學生、時期、課別、評量目標（題目類型）、評量方式（正確率／流暢性）、選項數或版面（呈現方法）、作答模式（大螢幕／紙筆）、提示方法、答錯規則、主題、正式或練習、日期（週／月） |
| 欄（第 2 個分組，選填） | 同上 |
| 篩選 | 上面所有欄位都能篩，另加日期區間、只看第一次作答 |

- 每一格同時顯示**筆數**；筆數太少（預設少於 5 筆）的格子變淡並提示「資料太少，僅供參考」。
- 可切換成長條圖或折線圖；結果與篩選後的原始紀錄都能匯出 Excel，方便用 SPSS 等軟體再分析。
- 常用的設定可以存成「我的比較」，下次直接開。
- 紀錄要補記的欄位：答錯規則、提示方法（目前只記用到的提示，要另記「當時設定」）、版面（第 0 階段一併加）。

## 4. 資料怎麼存

- 教材：`shared/lessons.js`（BOOKS、WORDS、WORDS_ED、SENT、SENT_ED、PICS、PARTS、CONF、CONF_ED、POLY_ED）。
  - 目前課本：翰林 2上、南一 2上、康軒 1上、康軒 2上、康軒 3上、康軒 4上。賓果原有的四本假設都是上學期，待確認。
  - 康軒二上（2026-10-20）：每課 18 習寫字＋1～2 認讀字；語詞 182 字用課本語詞，其餘取自字音字形檔、原有資料或由 Claude 擬定（擬定的 29 個語詞與部分形近字待維護者確認）。
  - 生字賓果的注音字型只收錄原本用到的字：康軒一上缺 20 字、二上缺 32 字，注音模式下這些字不會顯示注音；需用原始字型（ButTaiwan/bpmfvs）重新產生子集。
  - 新增課本的做法：在檔案最後加一段 `BOOKS.<代號> = {...}`，並視需要加 `WORDS_ED`、`SENT_ED`、`CONF_ED`、`POLY_ED`。識字評量會自動依版本、年級、學期排序，不用改程式。
  - `CONF_ED`：各版本自己的干擾字，優先於共用 `CONF`，避免影響其他版本。
  - `POLY_ED`：多音字（字 → 各唸法的例詞），保留給之後的多音字題型。
  - 第 0 課＝課前單元（例如康軒一上「真簡單」數字一到十），畫面直接顯示單元名稱；課次可有 `title`。
  - 康軒一上（2026-10-20）：語詞優先用課本語詞，其次用字音字形檔例詞，其餘 18 字及數字單元由 Claude 擬定並經維護者確認；形近字 27 字來自字音字形檔，其餘為擬定。
- 學生名單、教學日期、評量設定：瀏覽器 localStorage（`literacy-kids`、`literacy-teach`、`literacy-settings`、`literacy-ui`）。
- 作答紀錄：瀏覽器 IndexedDB（資料庫 `literacy`、store `records`），每題一筆，欄位見 `tools/literacy/app.js` 第 9 段的 COLS。
- 只存在老師自己的電腦＋瀏覽器；靠「下載備份檔（.json）」與「從備份檔還原」搬移。第 4 版規劃改用線上資料庫。
