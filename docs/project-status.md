## 3. 識字評量的設計（已定案）

### 評量目標（學習階段，建議順序但不強制）
| 目標 | 內容 | 狀態 |
|---|---|---|
| 1 聽音選圖 | 音 ↔ 義：聽語詞選圖片 | 第 2 版 |
| 2 看字選圖 | 形 ↔ 義：看字選圖片 | 第 2 版 |
| 3 形音辨識 | 聽「努力的努」，從同詞易混字、同音字、形近字中選出目標字 | **已完成** |
| 4-1 部件重組 | 看拆開的部件選字 | 第 3 版 |
| 4-2 看提示書寫 | 先用紙筆作答、老師登錄；自動評分之後再評估 | 第 4 版 |

### 正式評量 vs 練習（兼顧遊戲性與研究嚴謹度）
- **正式評量**：條件固定（選項數、提示、答錯規則都用「評量設定」的標準），出題為**純平均隨機**，結果納入學習分析。基線期固定無提示。
- **練習**：選項數、提示、答錯規則可自由調整；平均隨機時加入 **20% 常用字**（字頻最高的字，提高動機與成功經驗），結果另外統計。
- 20% 常用字**只用在練習**：放進正式評量會墊高正確率（內容效度）並造成測驗練習效應。紀錄有「常用字加題」欄位可篩除。
- 正式評量的出題方式固定平均隨機；常錯優先、字頻優先只開放給練習，且只有題數 ≠ 一課的量時才出現選項。
- 增強物（之後做）在正式評量依「完成題數」給、不論對錯；練習可依答對給。增強只出現在題目之間。

### 提示
- 層級 0 無提示；1 語詞挖空、句子；2 圖片、聲音；3 部件、遮擋字、字形；4～7 老師按鈕（口語、示範、肢體、完全提示）。
- 答錯規則（標準）：錯 1 打叉 → 錯 2、3 出下一個提示 → 錯 4 顯示答案並記為未通過。沒有資料的提示自動跳過。

### 評量時機（每位學生 × 每一課分別判斷）
1. 該課有教學日期 → 依日期：開始前＝基線期、期間＝教學中、結束後未滿 N 天＝教學後、之後＝維持期（N 預設 7）。
2. 沒有日期 → 比較學生「學習年級」與課本年級學期：還沒學到＝基線期；差 1 學期＝上學期學過；差 2～3＝上學年學過（皆為維持期）；本學期的課需老師輸入日期或按「還沒教」。
3. 學習年級＝有勾「課程調整（重整）」就用調整後年級，否則用目前年級。年級每年 8 月自動升級；8～1 月上學期、2～7 月下學期。
4. 學生可選填「本學期教學安排」：原班、資源班（抽離／外加）、學習扶助的每週節數與各自的開始日期，每學期一筆，用於比較介入前後。

### 畫面
- **快速開始（預設）**：今天要做什麼（課堂練習／小考檢測／計時挑戰）→ 誰要做 → 練哪幾課 → 開始。不出現術語，不要求評量時機。
- **進階設定**：六步驟完整版。系統記住這台電腦上次用的模式。
- **學生看得到的畫面一律顯示姓名**（輪到誰、結果、貼紙簿），沒填姓名才顯示代號；學生名單的姓名欄改為建議必填。老師畫面顯示「姓名（代號）」。姓名只存在這台電腦的瀏覽器，不進 repo。（2026-10-20 定案）

## 3-1. 賓果整合與增強系統（2026-10-20 定案）

夥伴已同意：生字賓果的玩法、主題、頭像、貼紙簿整合進識字評量。**不匯入賓果舊紀錄**，全部改用識字評量的紀錄格式。賓果在整合完成、夥伴試玩同意前照常使用，`tools/bingo/` 不修改。

- **主題**：海洋、太空、恐龍、甜點 4 個主題（＋無主題）變成所有評量共用的外觀，從賓果抽出放到 `shared/themes.js`、`shared/themes.css`。
- **主題只換外觀**：選項字大小、對比、位置、計時起點、提示、答錯規則和無主題時完全相同。
- **正式評量從基線期就套用主題與貼紙，全程不變**：避免「教學後才加入遊戲」和教學效果混在一起（單一受試研究的混淆）。學生可以自己挑主題，每筆紀錄記下 `theme`。
- **正式評量不播動畫**：作答中沒有背景粒子、怪獸動畫；題目間等待時間不變；流暢性模式只換配色。
- **增強規則**：正式評量**每完成一次評量抽一次**（不論對錯）；練習也是每次一抽，另可依答對或連線加抽。抽獎一律在結果畫面。每次給了什麼記入紀錄。
- **收藏以學生為單位**：平台共用模組（`shared/rewards.js`），用 IndexedDB 另開資料庫，以學生代號為鍵，存貼紙收藏與頭像。同網站的其他工具之後也能發貼紙。備份檔要一起包含。
- **頭像預設卡通角色，照片上傳為選填**：有需要的老師可以上傳（照片只存在老師電腦，隨備份檔保存）。改用線上資料庫前要重新評估照片是否上傳。
- **學生名單**：以識字評量的名單為平台名單（解決「名單是否共用」的待決問題）。
- **正式評量的選項與玩法固定（2026-10-20 維護者修訂）**：正式評量一律用「選項卡」（評量設定裡的固定選項數），不論換主題、換獎勵方式或之後新增玩法，選項的版面（數量、位置、大小、字型）都不能變形。
- **全課賓果卡不能用在正式評量**（會有連線的問題，學生可能為了連線而選字），只能用在練習等其他模式。（取代原本「賓果卡版面可當正式評量選項方式」的規劃）
- **打怪獸玩法跟著作答模式走（2026-10-20 維護者修訂）**：個人答題＝自己打怪獸；多人答題（大螢幕輪流、之後的同步答題）＝合作打怪獸。練習一律可以用。
- **正式評量的打怪獸（2026-10-20 維護者確認保留）**：做成「評量設定」裡的開關，預設關閉（要做研究的老師維持關閉），老師可以打開。開啟時必須遵守：
  1. 選項版面完全不變（和沒有打怪獸時一樣，自動化測試比對）。
  2. 怪獸受傷依「完成題數」，不論對錯（和貼紙規則一致），避免答錯的學生看到怪獸沒受傷而洩氣、影響後面的作答。
  3. 作答中畫面完全靜止；怪獸受傷、蛋裂開、蛋糕疊高等圖案變化，全部移到題目之間、不用作答的固定長度過場裡呈現，不影響反應時間的計時。
  4. 同一位學生從基線期就決定要不要打怪獸，之後所有時期都一樣；每筆紀錄的 `game` 欄位記下，進階分析可以分開看。
- **打怪獸的戰利品＝這次的貼紙（2026-10-20 維護者提出，和增強制度合併）**：打敗怪獸得到的東西直接收進貼紙簿——海洋釣到的大魚、恐龍谷孵出的恐龍（沿用賓果的扭蛋圖鑑）、太空打敗外星人得到的星球、甜點店做好的杯子蛋糕。**它就是這次評量的那一張貼紙，不是多送一張**：有打怪獸和沒打怪獸的學生，每次評量都是剛好一張，增強的份量一樣，正式評量才比較得起來。中途結束一樣不給。
- **輪流答題的換人過場（所有模式都適用，含正式評量）**：換人時，下一位學生的頭像和名字要很明顯（大頭像＋大字「換 ○○」），過場後停約 1 秒再出題，讓學生有時間換位置。計時從題目唸完才開始，停頓不影響反應時間。
- **注音字型**：用原始字型（ButTaiwan/bpmfvs）依 `shared/lessons.js` 全部字＋干擾字重新產生子集，獨立存成 `shared/fonts/`；破音字讀音表一起補。

## 3-2. 老師專區（分析）設計（2026-10-20 定案）

參考賓果老師專區的呈現方式（數字卡、折線圖、常錯字、容易搞混的字、字的精熟歷程表），但依識字評量的紀錄格式重新做。**不一次攤開所有數據，用選單逐步選，每次只顯示一張圖或一張表＋上方 3 個重點數字**，明細按「看明細」才展開。

| 選單 | 選項 |
|---|---|
| 1 看誰 | 一位學生（預設）；多位學生比較（全班總表：學生 × 生字，格子顯示正確率） |
| 2 怎麼看 | 依時間（橫軸選「測驗日期」或「教學時間」＝教學開始後第幾天，對齊各課教學日期）；依課別；依時期比較（基線期／教學中／教學後／維持期並排） |
| 3 範圍 | 本學期（預設）、上學期、自訂起訖日期、某一時期；另可篩正式評量（預設）或練習、評量目標、課次 |
| 4 看什麼（一次一個） | 錯誤率（正確率）、反應時間、流暢性（每分鐘正確數）、間隔（教學後天數、距上次評量天數）、常錯字排序、高字頻生字（常用字）錯誤率、錯誤類型、提示層級 |

- 選單只顯示合理的組合：趨勢類（正確率、反應時間、流暢性）畫折線圖；排序類（常錯字、錯誤類型、高字頻）顯示排序表。
- 依時間的折線圖：虛線分隔各時期，並標出教學安排（原班／資源班／學習扶助）的開始日；流暢性可畫目標線。
- **逐字學習紀錄**：任何畫面點一個字，就看到那個字的每次作答（日期、時期、目標、對錯、秒數、選錯成哪個字、提示層級、當時的時期）。
- 目前畫面的資料可以匯出 Excel。
- 高字頻生字錯誤率需要先有字頻資料（維護者之後提供）；沒有資料時這個選項先不出現。
- **分析與比較一律用時期（基線期／教學中／教學後／維持期）判斷。**（2026-10-20 定案）
- **學習階段（獲得／流暢／精熟／維持）保留為簡單的效果檢核**：老師專區基本頁面有一張「學習成效一覽」，每個字標出已達習得、精熟、維持或還沒達到，讓老師大略瀏覽；不放進進階分析。判斷標準待討論（見待決問題）。
- **間隔兩種都要**：教學後天數（該課教學結束到這次評量）、距上次評量天數（同一學生同一字）。

### 第 2 階段的實作細節（2026-10-20）
- 右上角「老師專區」，三個分頁：一位學生、全班總表、進階分析（研究用）。中途結束的紀錄一律不算；預設只看正式評量、本學期。
- 一位學生：看誰 → 看什麼 → 怎麼看（趨勢類才有）→ 範圍（日期、正式／練習、課本與課次、評量目標）。每次一張圖＋3 個重點數字＋「看明細」表格＋匯出 Excel。
  - 正確率＝第一次就答對的比例；反應時間＝答對題的平均秒數；流暢性＝每回合第一次就答對的題數 × 60 ÷ 時限。
  - 依時間：橫軸可選測驗日期（每次評量一個點）或教學開始後第幾天（只算有教學日期的課）；時期改變處畫虛線並標時期；教學安排開始日畫直線；流暢性畫目標線。
  - 間隔分組：教學後天數（教學前或教學中／0～6／7～13／14～29／30 天以上）、距上次評量（第一次考／同一天／1～6／7～13／14～29／30 天以上）。
- 全班總表：學生 × 生字，格子是第一次就答對比例與次數，顏色只用一種藍色（越深越好）。
- 逐字學習紀錄：任何畫面點字就打開，列出那位學生那個字的每一次作答（含標註的中途結束），可匯出。
- 進階分析：1 個指標（筆數、正確率、錯誤率、答對秒數、第一次作答秒數、流暢性、提示層級、用到提示比例、顯示答案比例、兩種間隔天數）× 列 × 欄（23 種分組），2 個篩選、日期、只算每個字第一次作答、排序、筆數提醒門檻、長條圖／折線圖、存成我的比較、匯出結果＋原始紀錄。目前一次一個指標。
- 圖表顏色依資料視覺化規範：一條線用第 1 色，多組用固定順序 8 色（已用色盲檢查工具驗證，淺色組靠表格與標籤輔助）；格線是實線細線，只有時期分隔用虛線（單一受試研究的慣例）。
- 自動化測試用已知答案的假資料逐項比對（21 項全部通過），包含進階分析與從原始紀錄直接算的結果一致。

### 進階分析（研究用，平常收起來）

給有研究需求的老師做交叉比對。放在老師專區的「進階分析」分頁，一般老師不會看到。做法是「樞紐分析表」（像 Excel 的樞紐分析：選要比什麼、依什麼分組，系統算出每一格的數字）。

| 設定 | 可以選 |
|---|---|
| 指標（一次一個或多個） | 錯誤率、反應時間（第一次作答／答對秒數）、流暢性、間隔、常錯字排序、高字頻生字錯誤率、錯誤類型分布、提示層級 |
| 列（第 1 個分組） | 字、學生、時期、課別、評量目標（題目類型）、評量方式（正確率／流暢性）、選項數或版面（呈現方法）、作答模式（大螢幕／紙筆）、提示方法、答錯規則、主題、正式或練習、日期（週／月） |
| 欄（第 2 個分組，選填） | 同上 |
| 篩選 | 上面所有欄位都能篩，另加日期區間、只看第一次作答 |

- 每一格同時顯示**筆數**；筆數太少（預設少於 5 筆）的格子變淡並提示「資料太少，僅供參考」。
- 可切換成長條圖或折線圖；結果與篩選後的原始紀錄都能匯出 Excel，方便用 SPSS 等軟體再分析。
- 常用的設定可以存成「我的比較」，下次直接開。
- 紀錄要補記的欄位：答錯規則、提示方法（目前只記用到的提示，要另記「當時設定」）、版面（第 0 階段一併加）。

## 3-3. 整合的分階段計畫（2026-10-20 定案順序：0 → 1 → 2 → 3）

### 血量模式（3-3b，2026-10-20 維護者定案）
- **只在練習**（正式評量提早結束會讓資料不完整）。

- **多人輪流**：個人模式＝每人各自的愛心，某人用完就換下一位繼續、他的部分結束；合作模式＝全組共用愛心，用完全組一起結束。
- **實作細節（2026-10-20 完成）**：
  - 選主題畫面多一列「愛心：不用／3 顆／5 顆／7 顆」，只在練習的正確率模式出現（流暢性、正式評量沒有），這台電腦記住上次的選擇（`settings.practiceHearts`，預設不用）。全課賓果卡也可以用。

  - 「連續答對」指連續幾題第一次就答對；答錯會重新算。
  - 作答畫面上方一排愛心，少一顆時碎掉、補一顆時跳出來。用完時顯示「○○的愛心用完了！」1.6 秒，個人模式寫「換下一位繼續」。
  - 紀錄多 `hpMax`（開始幾顆）、`hp`（這題做完剩幾顆）；Excel 有「愛心（開始時）」「愛心（這題後剩下）」，進階分析可依「血量模式」分組。愛心用完的那次不算中途結束。
  - 打怪獸時愛心用完：不會打敗怪獸，直接到結果畫面，貼紙一樣一張（戰利品照常揭曉）。
- **之後的增強方式（再討論）**：轉蛋、抽獎、轉盤等，**剩幾顆愛心就抽幾次**（例如剩 5 顆抽 5 次）。這是依表現給獎勵，只用在練習；正式評量維持「做完一次抽一張、不看對錯」。

### 多人合作破關遊戲（3-7，2026-10-20 維護者提出，之後再做）
參考 Kahoot 合作模式、Blooket：大家輪流答題，一起破關。
- **累積型**：答對累積技能條，集滿（或時間到）就攻擊怪獸；逃跑遊戲累積逃跑速度；賽車遊戲累積加速。
- **分階段**：例如每答對 3 題進入一個小遊戲，玩完再回來答題。
- 原則：只在練習；小遊戲和動畫只出現在題目之間，不影響反應秒數的計算；每人每題仍各記一筆。
- 開工前要討論：先做哪一種（攻擊怪獸、逃跑、賽車）、小遊戲要玩多久、有沒有時間限制、和打怪獸（3-3）共用哪些圖。

## 3-4. 備課分析（2026-10-20 新增）

給老師備課用：選課本（可多本，例如同年級）、勾課次或存好的段考範圍，統計範圍內常見部件，作為集中識字（部件識字、基本字帶字）的教學重點參考。

- 範圍：課本可複選；課次可勾選；字的種類（習寫＋認讀／只習寫／只認讀）。常用範圍存在瀏覽器 localStorage（`prep-ranges`），畫面狀態存在 `prep-ui`。
- 分析方式：第一層部件（字直接拆開）或拆到最細（部件再往下拆）；預設隱藏單一筆畫；可設定「至少出現在幾個字」。
- 結果：三個重點數字＋三個分頁。部件排行列出出現字數、出現率、範圍內的字、**學過的舊字**（同版本、比範圍更早的課，用來新舊字串聯）；生字一覽列出每字部件與語詞；字頻分頁在 `FREQ`（字 → 排名）存在時才有內容。目前分頁可匯出 Excel。
- 部件來源：先用 `lessons.js` 的 `PARTS`（人工），沒有再用 `shared/parts.js` 的 `PARTS_AUTO`（cjkvi-ids 自動拆解，GPLv2，優先台灣字形；罕用部件再往下拆成常見部件；相容表意字轉回一般字；無法編碼的部分略去）。
- 已知限制：自動拆解是「字形結構」，不一定等於教學用部件，例如「王」拆成一＋土、「只」拆成口＋八。發現錯誤可直接改 `shared/parts.js`，或在 `lessons.js` 的 `PARTS` 加人工拆法（優先採用）。重新產生 `parts.js` 會覆蓋手改內容，所以人工修正建議寫在 `PARTS`。
- 待做：字頻／詞頻資料（`FREQ`）、部首與筆畫（Unicode Unihan 或全字庫，目前開發環境連不到）、課文詞頻（需要課文）、課本的下學期與「學年度」。
