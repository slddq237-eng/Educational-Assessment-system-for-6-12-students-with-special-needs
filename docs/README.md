# 文件索引（先讀這份）

給接手這個 repo 的 Claude（和人）看的交接文件入口。**不用全部讀完**：先讀這一頁，再依要做的工作，只讀下面表格列的檔案。
2026-10-22 起，原本的 `docs/project-status.md`（約 5 萬字）拆成下面幾個小檔案，避免一次讀太多、讀到過時的內容。

## 寫文件的規則

- 新決定記在上表對應的檔案；改變決定時**直接改寫現況**，舊的說法移到 `history.md`，不要讓新舊說法並存。
- **精簡、重整、拆分文件時不直接刪內容**（2026-10-24 維護者決定）：拿掉的段落原文搬到 history 檔案（決定的歷史 `history.md`、教材 `history-materials.md`、路線圖已完成項目 `history-roadmap.md`；都不適合就在 `history.md` 加一節），原處留一句「見 ○○」。只有錯字、重複的同一句話可以直接刪。PR 說明寫出每一段搬去哪裡。
- 單一檔案超過約 10,000 字，自動檢查會提醒該拆了。
- 檔案內文寫的「見 3-1」「第 2-1 節」是原本 project-status 的節號，用上表找在哪個檔案。
