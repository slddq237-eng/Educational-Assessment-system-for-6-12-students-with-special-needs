資料與隱私說明

給學校、家長和使用這個平台的老師：學生的資料存在哪裡、會不會上網、老師要注意什麼。

回平台首頁
一句話：學生的名字、作答紀錄、照片都只存在老師自己電腦的瀏覽器裡，不會上傳到任何伺服器。這個網站沒有帳號、沒有後台資料庫，維護的老師也看不到任何人的資料。

存了哪些資料、存在哪裡

資料存在哪裡說明
學生名單（代號、名字、年級）老師電腦的瀏覽器名字是選填的。共用電腦建議只填代號。
作答紀錄老師電腦的瀏覽器每題一筆：考哪個字、選了什麼、幾秒、用了什麼提示。用學生代號存。
頭像、貼紙收藏老師電腦的瀏覽器預設用卡通動物。上傳照片是選填，照片會縮小後存在這台電腦；上傳前建議先取得家長同意。
教學日期（可以依學生不同）、評量設定、每課要考的字（字組）老師電腦的瀏覽器不含學生名字；個別學生的教學日期只用學生代號。
字組檔（.json，分享給同事用）老師自己下載的檔案只有每課要考哪些字，沒有學生資料，可以寄給同事。
平板作答的紀錄（選用）老師自己的 Google 表單與試算表只有作答模式選「平板掃 QR code」時才有。送到表單的紀錄只有學生代號，沒有名字；平板上不留作答紀錄。QR code 裡有這次練習的設定和學生名字（讓學生在平板上點自己的名字），只給學生掃，不要貼到公開的地方。
備份檔（.json）、匯出的 Excel老師自己下載的檔案裡面有學生名字和成績，見下方「老師要注意」。

「瀏覽器」指的是 Chrome、Edge、Safari 這些上網的程式。資料只在同一台電腦、同一個瀏覽器、同一個網址看得到；換電腦或換瀏覽器就看不到，要用備份檔搬過去。

網站會連到哪裡

打開網頁時會從下面這些地方下載網頁、字型和程式元件。這些服務會收到一般的連線紀錄（例如 IP 位址），不會收到學生資料。作答時不需要連網（平板作答除外，見下方）。

  • GitHub Pages：放網頁的地方。
  • Google Fonts：網頁用的中文字型。
  • 老師自己的 Google 表單（平板作答，選用）：學生用平板做完練習後，把作答紀錄（學生代號，沒有名字）送到老師自己建立的 Google 表單，存在老師的 Google 帳號。
  • Google 表單：只有按「問題回報」時才會打開。填寫內容會存在 Google，請勿填學生的姓名、成績、照片。

語音唸讀用的是瀏覽器內建的語音。有些瀏覽器的語音（例如 Chrome 的「Google 國語」）會把要唸的文字送到雲端合成，所以：

  • 題目只唸生字和語詞，例如「努力的努」。
  • 需要唸學生名字的地方（得到貼紙、換人提醒），只用電腦內建的語音；找不到內建語音時就不唸名字。

老師要注意

  • 每週下載一次備份檔（識字評量右上角「選單 → 下載備份檔（換電腦用）」），存到隨身碟或學校的雲端硬碟。
  • 換電腦、換瀏覽器、清除瀏覽器資料之前，一定要先下載備份檔，到新電腦再按「選單 → 匯入檔案」。清除瀏覽資料後，紀錄就找不回來了。
  • 不要用無痕視窗：關掉視窗後，名單和紀錄都會不見。
  • 備份檔和 Excel 裡有學生名字和成績：不要傳到公開的雲端、群組或社群；檔名不要寫學生姓名；不用了就刪除。
  • 用平板作答時，Google 試算表裡有學生代號和作答紀錄：表單和試算表不要分享給不相關的人；用在研究或論文前，要另外取得家長同意。
  • 共用電腦（例如教室電腦）的其他人打開同一個網站看得到名單和紀錄。共用電腦請只填代號，或用自己的電腦。
這一頁說明平台本身怎麼存資料，不能取代學校的個資規定。使用前請依學校的規定辦理；有疑問請洽平台維護老師。

發現問題或有建議：問題回報（Google 表單，會開新分頁；填寫內容存在 Google，請勿填學生資料）。

平台用到的外部資料與出處見關於我們。這一頁的內容對應平台規格書「資料來源、授權與隱私」一節。平台加入新功能（例如錄音）時會先更新這一頁。
