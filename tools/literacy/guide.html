學扶前後測快速指南

給學習扶助、資源班老師：做前測、教學中檢測、後測，圖表可以直接用在心評報告。右邊的示範畫面會自己播放，紅圈就是要點的地方。

打開識字評量 回平台首頁
① 只做一次，約 5 分鐘建學生名單學生名單 → 填代號、名字、年級 → 本學期安排 ② 每次評量點 4 下就開始學扶前後測 → 現在是？ → 學生、課次 → 開始 ③ 寫報告看依時期比較老師專區 → 一位學生 → 正確率 → 依時期比較

1第一次使用：建學生名單

  1. 按右上角 學生名單。
  2. 填代號、名字（學生作答時看得到）、年級。
  3. 按 本學期安排，填學扶每週幾節、開始日期。圖表會在這一天畫一條線。
  4. 按 完成。

字的大小、唸讀速度在右上角「畫面與聲音」調整（選填）。

2每次評量：點 4 下就開始

  1. 點 學扶前後測（這台電腦會記住，下次打開就停在這裡）。
  2. 現在是？選 教學前、教學中 或 教學後。
  3. 點學生（最多 4 位輪流）、選課次。
  4. 按 開始評量 → 學生選主題 → 作答 → 抽一張貼紙。

選項數、提示、答錯規則都已固定，不用設定。教學前不給提示。

3什麼時候做？

選哪一個什麼時候做幾次
教學前（前測）開始教這幾課之前至少 3 次、不同天
教學中教學期間每 1～2 週 1 次
教學後（後測）教完那一週1～2 次
教學後（維持）教完 2～4 週後1～2 次

日期不用自己記：第一次選「教學中」的那天＝教學開始日，第一次選「教學後」的那天＝教學結束日，結束 7 天以上自動算維持期。記錯了到「進階設定 → 教學日期管理」修改。前測到後測請用同一台電腦、同樣的課次。

4寫報告：看依時期比較

  1. 按右上角 老師專區 → 一位學生。
  2. 看誰：點學生；看什麼：正確率。
  3. 怎麼看：依時期比較。前測、教學中、後測的正確率並排，最直接看出介入有沒有效。

「依時間」是折線圖，會標出學扶開始日。每個畫面都能匯出 Excel。名詞和其他圖的看法見分析教學。

!一定要記得

  • 讓學生做完：中途按「結束」，那一次的紀錄不算。
  • 每週備份：紀錄只存在這台電腦。按「作答紀錄 → 下載備份檔」存到隨身碟或雲端；換電腦用「從備份檔還原」。
  • Excel 和備份檔有學生名字：不要傳到公開的地方或群組。
  • 不要用無痕視窗：關掉後紀錄會不見。
  • 給學校、家長看的說明：資料與隱私說明。
