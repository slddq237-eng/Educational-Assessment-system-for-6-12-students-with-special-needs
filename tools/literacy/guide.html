學扶前後測快速指南

給學習扶助、資源班老師：用「識字評量」做轉介前介入（RTI）的前測、教學中檢測和後測，資料可以直接用在心評報告。

打開識字評量 回平台首頁

1第一次使用（約 5 分鐘）

  1. 打開識字評量，按右上角 學生名單。
  2. 每位學生填代號、名字（學生作答時看得到）、年級；點頭像可以換卡通角色。
  3. 按 本學期安排，填學習扶助（或資源班）每週幾節和開始日期。老師專區的圖會在這一天畫一條線，寫報告時可以說明介入從哪天開始。
  4. （選填）右上角 畫面與聲音：調字的大小、唸讀速度、音效。

2每次評量（4 個步驟）

  1. 快速開始點 學扶前後測（這台電腦會記住，下次打開就停在這裡）。
  2. 現在是？選 教學前、教學中 或 教學後。
  3. 點學生（最多 4 位輪流，換人時畫面會大大顯示下一位的名字）、選課次。
  4. 按 開始 → 學生選主題 → 作答 → 做完抽一張貼紙。

選項數、提示、答錯規則都已固定，不用設定。教學前固定不給提示。

3什麼時候做？

選哪一個什麼時候做幾次系統會自動做的事
教學前（前測）開始教這幾課之前至少 3 次、不同天，看起點穩不穩算基線期，不給提示
教學中教學期間每 1～2 週一次第一次選的那天記成這幾課的「教學開始日」
教學後（後測）教完那一週1～2 次第一次選的那天記成「教學結束日」
教學後（維持）教完 2～4 週後1～2 次結束 7 天以上自動算「維持期」

同一位學生從前測到後測，請用同一台電腦、同樣的課次範圍；主題可以讓學生自己選，貼紙每次固定一張，不影響成績比較。日期記錯可以到「進階設定 → 教學日期管理」修改。

4寫報告要看哪裡

右上角 老師專區 → 一位學生，日期選 全部：

  • 正確率 → 依時期比較：前測、教學中、後測、維持期的正確率並排，最直接的介入成效。
  • 正確率 → 依時間：折線圖，虛線分出各時期，直線標出學扶開始日。
  • 反應時間：越來越快代表越熟練。
  • 常錯字排序、錯誤類型：還沒學會的字、常搞混的是形近字還是同音字，可寫進教學建議。
  • 點任何一個字，看那個字的每一次作答。

每個畫面都可以「看明細」和「匯出這個畫面（Excel）」。報告用的一鍵摘要之後會再加上。

5一定要記得

  • 中途按「結束」：那一次的紀錄不算、也沒有貼紙，請盡量讓學生做完。
  • 紀錄只存在這台電腦的瀏覽器：每週按「作答紀錄 → 下載備份檔」，存到隨身碟或雲端；換電腦時用「從備份檔還原」。
  • 匯出的 Excel 和備份檔有學生名字：請妥善保管，不要傳到公開的地方或群組。
  • 不要在無痕視窗使用，關掉後紀錄會不見。
  • 給學校、家長看的說明：資料與隱私說明。
有問題或想調整，請洽平台維護老師。
